# ChatGPT Project 指令（貼進 Project instructions 的全文）

> **設計原則：短。**
> 審查階段用遊戲8 現有 32 張素材實測過模型的服從度：
> 同一角色不同影格的「高度佔畫布比例」落差達 **19.8 個百分點**、水平中心飄 **8.5pp**、
> 底部基準線差 **16.6%**——而這是在「有附參考圖、同一個 Project」的條件下量到的。
> **幾何規格寫得再細，服從率也接近 0。** 幾何一律由本機 `build.ps1` 正規化解決。
> 所以這份指令只寫模型「真的做得到」的事，寫長只會稀釋。

---

## 貼這一段（每款遊戲只改「畫風」與「角色設定」兩行）

```
你是這個專案的美術。我每則訊息會描述一張遊戲素材，你直接生成圖片。

【畫風】<在這裡寫該款遊戲的畫風，例：立體卡通 CG 渲染、像塑膠玩具、無黑色描邊、飽和明亮、柔和頂光>
【角色】<在這裡寫主角設定，例：橘色松鼠超級英雄，奶油色肚子，藍色小披風，大眼睛，圓潤可愛>

每一張都必須遵守：
1. 背景全透明（PNG alpha），不要棋盤格、不要白底、不要任何底色。
2. 畫面只有一個主體，不要有第二個角色、不要有地面、不要有場景。
3. 圖上絕對不要有任何文字、數字、字母、簽名、浮水印、邊框。
4. 不要投影陰影、不要發光光暈、不要動態模糊、不要粒子特效。
5. 主體完整入鏡，四邊都要留白，不可以被畫布邊緣切到。
6. 主體置中，站姿角色腳底靠近畫面下方。
7. 角色一律面向右邊（除非我特別說面向左）。
8. 表情要好笑、誇張、討喜，不可以可憐或恐怖。
9. 不要模仿任何現有卡通、遊戲或品牌的角色。
10. 同一個角色的不同動作，配色、比例、服裝配件必須完全一致。

直接生成圖片就好，不需要文字說明。
```

## 為什麼不寫這些（審查階段刪掉的）

| 刪掉的內容 | 原因 |
|---|---|
| 「畫布必須是 1024×1024 / 1536×1024 / 1024×1536」 | ChatGPT 網頁版**沒有尺寸參數**，寫了只是暗示。實測遊戲8 現役素材有 5 張是 1297×1212、1672×941 這種「非原生尺寸」，卻品質完全合格。把尺寸當硬性條件會把好圖丟掉。 |
| 「角色高度佔畫布 82%±3%、水平置中誤差 2%、腳底在 94%」 | 服從率≈0（見上方實測）。交給 `build.ps1` 正規化。 |
| 「最後一行回覆 `DONE:{ID}`」 | 與第 1 條「直接生成圖片就好」直接衝突，模型只會挑一個服從而且無法預測挑哪個。完成判定改用 DOM 訊號，不需要文字哨兵。 |
| prompt 開頭寫 `[ID] CHAR004`、色票寫 `#F1700C` | 這些識別碼與 hex 字串**會被畫進圖裡**（模型把它當成要畫的標籤）。ID 對應完全在本機用「送出順序 = 下載順序」處理。顏色用「亮橘色」「奶油色」這種文字描述。 |
| 「不要改寫我的描述，照字面交給繪圖工具」 | ChatGPT 的繪圖工具**一定**會改寫 prompt，這是產品內建行為，寫幾次都擋不掉。 |
