## 一、現況（全系列第一款，2026-06 上線的 2D Canvas 版）

**一句話**：小玩家的身體就是搖桿——火箭從發射台 3、2、1 升空後一路往上飛，身體左右移動控制火箭左右、接住從上面掉下來的星星和禮物；雙手高舉就噴大火衝刺。收集 5 顆星後炸彈登場，碰到會「碰！」翻滾三圈（小玩家的最愛，會故意去撞）。沒有 Game Over。

### 版面（直式上升、單畫面）

```
      ⭐    🎁     💣(閃紅光)          ← 掉落物從上方落下，左右微幅飄
   🪐        🌕        🛸             ← 背景星球慢慢飄過、小星星閃爍
              🚀                      ← 火箭固定在畫面下方 78% 高度，只左右移動
 [⭐ 星星數]                           ← HUD
```

- 現在**所有美術都是程式畫的**：火箭是 canvas 貝茲曲線拼的、掉落物與星球全是 emoji、背景是純漸層。**看起來很陽春，這就是要重製的原因。**
- 背景只有「深藍太空漸層」一種，飛一小時畫面也不會變，**沒有「越飛越高」的感覺**。

### 體感輸入（已驗證可靠，重製不可以改）

| 身體動作 | 遊戲操作 | 手指模式 |
|---|---|---|
| 身體左右移動（連續值） | 火箭左右飛（平滑跟隨） | 拖曳左右 |
| 雙手高舉（兩手腕都高過頭） | 🔥 衝刺：火焰變大、速度加倍、背景星星拉成線 | 兩指按住 |

**整款只有這兩個訊號，不可以再加。**（這款試過三版精細手勢全部誤觸，最後移除，是全系列「只用大動作」鐵則的起點。）

### 玩法機制（玩得很好，要保留）

1. **發射序曲**：3、2、1 倒數 → 火箭從發射台噴煙升空、畫面震動。這段儀式感小玩家很愛。
2. **接星星**：⭐ 從上方掉下來，70% 出現在火箭附近搆得到、30% 遠處鼓勵跑動。每 10 顆放煙火＋英文稱讚；每 20 顆火箭升級換新顏色。
3. **🎁 禮物盒**：碰到爆出一堆驚喜（彩虹、獨角獸、冰淇淋、小狗…亂飛）。
4. **💣 炸彈（收集 5 顆星後才登場）**：有紅色閃光警告。碰到 →「碰！」掉最多 3 顆星、**整支火箭翻滾三圈**、畫面大震、之後閃爍 1.5 秒無敵。**這是小玩家全遊戲最愛的部分，會故意去撞**，重製要做得更誇張更好笑。
5. **衝刺**：雙手高舉噴大火，掉落物變快、星星刷刷刷往下衝，爽感來源。
6. 沒有 Game Over、沒有計時、星星掉了撿回來就好。
7. 護眼機制：太靠近電視 → 警報＋強制暫停 5 秒倒數（全系列共用，不用你設計）。

### 目前的旁白（英文，重製會改用 Gemini TTS 全部重錄）

## 二、這次重製要你做什麼

### 階段 0（Claude 已指定，你不用選）

| 指定項 | 值 |
|---|---|
| **引擎** | **2D Canvas 直式上升＋`drawImage` 貼圖**（沿用現有架構：火箭固定在畫面下方偏中，掉落物由上而下、背景往下捲表現上升）。**不是**橫向捲軸、不是偽 3D。 |
| **視角統一** | 所有東西都畫**正面（面向鏡頭）的卡通視角**：火箭畫正面（看得到大眼睛與窗戶），掉落物、炸彈、背景星球、NPC 全部正面或四分之三面。 |
| **素材預算** | **總共約 28～32 張，分 4 批**（每批 6～8 張）。設定圖另計。 |

### 企劃加料的方向（重點）

1. **高度系統（最重要的一項加料）**：現在飛再久畫面都一樣。請設計「越飛越高、世界跟著換」的分層場景——例如 城市上空 → 雲海 → 高空彩虹層 → 外太空 → 月球/糖果星球…（層數與內容你規劃，配合素材預算）。每進一層要有明顯的儀式感（換背景色調、換背景景物、旁白慶祝），讓小玩家有「我飛好高！」的成就感。收集星星＝上升動力這個關聯可以做明確一點。
2. **炸彈更好笑**：翻滾要更誇張（暈臉、吐舌、冒星星），炸彈本身做成圓滾滾的壞壞反派臉（好笑不恐怖，參考遊戲6 火苗的定位）。可以設計撞到後的隨機搞笑演出。
3. **禮物盒驚喜升級**：爆出的東西可以更瘋、更多樣，甚至偶爾爆出短暫的搞笑事件（你設計）。
4. **路上多點朋友**：背景可以有揮手的 NPC（熱氣球、小鳥、UFO 外星人…），讓世界熱鬧、有縱深，但不干擾判斷（明顯在背景層、不重疊掉落物）。
5. 旁白全部重寫：活潑、短、有情緒，英文。

**不能動的主線**：左右移動接星星／閃炸彈、雙手高舉衝刺、每 10 顆煙火、撞炸彈翻滾不懲罰結束、沒有 Game Over、沒有時間壓力。

### 你要交的東西（依序）

1. **企劃書**（格式照 04）：以上面的玩法為基礎重新規劃、把加料方向具體化。
2. **場景設計**（格式照 04）：把各高度層設計成分層構圖（遠景／中景／掉落物層／主角層／HUD），要有縱深、熱鬧但不雜亂（電視上東西很小）。**背景漸層與星空由程式畫**，你設計的是每一層的色調與「單體背景景物」（雲、星球、熱氣球…由程式擺放、依層出現）。
3. **設定圖**：至少三張——`REF001` 火箭主角（正面主圖＋衝刺形態＋暈臉表情；擬人化大眼睛）、`REF002` 掉落物家族（星星、禮物、炸彈反派＋你新增的道具，同一張定調）、`REF101` 世界縱剖全景（由下而上把各高度層的色調與景物畫在一張直式長圖上，當各層的色彩與造型基準）。
4. **素材清單**（JSON，格式照 04）：`輸出` 一律留 `{}`。

### 素材設計的硬性提醒（程式端限制）

- **火箭主角**至少四張：**直飛**、**傾斜轉向中**（車身側傾，只畫一側，程式水平鏡像做另一側）、**被炸暈**（眼睛圈圈、吐舌；程式拿這張整支旋轉做翻滾三圈）、**衝刺**（火焰全開、表情熱血）。**尾焰直接畫在圖上**，每張的火焰大小配合狀態；衝刺另可加一張獨立「大火焰」素材讓程式疊加（你決定）。
- **掉落物**每種一張、正面、左右對稱、圓圓亮亮有臉；**炸彈**要一眼看出是「要躲的壞蛋」（警告紅光由程式畫，**圖上不要畫光暈**）。
- **背景景物**（雲、星球、熱氣球、UFO、小鳥…）每個一張，單一主體、適合縮小、依高度層分配。
- **發射台**：開場那一幕的地面／發射架景物（可以是一張橫幅，只在開場用）。
- **特效**：爆炸雲、翻滾星星、煙火、衝刺速度線之類，每種一張（程式也會補粒子）。
- 每一層的背景色調要跟 REF101 一致，讓「換層」一眼看得出來。
- 所有素材**不要有文字、字母、數字**。
