# 遊戲1-火箭冒險 場景設計

## 一、畫面分層

本款採用直式上升的 2D Canvas 單畫面。火箭固定在畫面下方偏中，只做左右位移、側傾、縮放、旋轉與狀態影格切換；掉落物與背景景物由上往下移動，製造持續升空的感覺。所有角色與物件統一使用正面朝向鏡頭或正面偏四分之三面的卡通視角，不使用側向捲軸構圖。

背景漸層、小星點、速度線、紅色炸彈警告、文字與簡單粒子由程式繪製；遊戲素材負責火箭、掉落物、代表景物、背景朋友與表演特效。

### 遠景

| 項目 | 設計 |
|---|---|
| 內容 | 各高度層的天空或太空底色、極簡小星點、遠方空氣色 |
| 動態 | 天空色隨高度平滑轉換；一般飛行時以最慢速度向下捲動，衝刺時稍微加快；太空小星點緩慢下降 |
| 素材 ID | 無，全部由程式繪製 |
| 分層作用 | 建立最大面積的高度差異，不放可碰撞物，也不使用會搶走注意力的高對比細節 |
| 視差速度 | 以掉落物速度為 1，遠景約為 0.15～0.2 |
| 遮擋規則 | 永遠位於所有圖片素材後方 |

遠景依高度分成五套明確色調：

1. 糖果城市上空：亮天藍到清澈湖水藍。
2. 鬆軟雲海：明亮青藍到偏白的天空藍。
3. 彩虹高空：高明度亮青色到純淨藍色。
4. 閃亮外太空：深寶藍到鈷藍，不使用純黑背景。
5. 月球與糖果星系：深藍底加入明亮青藍色空氣帶，維持玩具世界的友善感。

### 中景

| 項目 | 設計 |
|---|---|
| 內容 | 發射台、城市天際線、雲朵、熱氣球、小鳥、彩虹、飛碟、月球、環形星球、糖果星球 |
| 動態 | 隨世界向下移動，速度慢於掉落物；單體景物可輕微左右漂移、旋轉、縮放及淡入淡出 |
| 素材 ID | BG001、BG002、FX001～FX008 |
| 分層作用 | 表現目前高度、提供背景朋友與縱深，但不參與碰撞 |
| 視差速度 | 以掉落物速度為 1，城市與大型星體約為 0.25～0.35；雲、熱氣球、小鳥與飛碟約為 0.35～0.45 |
| 遮擋規則 | 不進入火箭附近的主要操作區，也不遮住星星、禮物或炸彈 |

中景的配置原則：

- `BG001` 是開場專用的滿寬發射台橫幅，只在倒數與升空時出現，不重複拼接。
- `BG002` 是糖果色城市天際線橫幅，從畫面下方延伸出城市上空的高度感；進入雲海時向下離場並淡出，不做無限重複。
- `FX001` 雲朵以數張不同縮放與左右位置的副本組成雲海，避免排成整齊水平線。
- `FX002`、`FX003`、`FX005` 是背景朋友，優先從畫面兩側經過，保留中央與火箭左右移動範圍給掉落物。
- `FX004` 彩虹是彩虹高空的代表景物，放在中景後側緩慢下降，不作為可收集物。
- `FX006`～`FX008` 尺寸明顯大於掉落物、移動明顯較慢，並降低對比，避免被誤認為可碰撞目標。
- 所有背景朋友不投下陰影、不帶光暈，也不與火箭或掉落物發生遮擋穿插。

以火箭主體高度為 1 的程式排版參考：

| 中景元素 | 相對高度 |
|---|---:|
| 小鳥 | 約 0.18～0.24 |
| 熱氣球、飛碟 | 約 0.35～0.5 |
| 單朵雲 | 約 0.45～0.9 |
| 彩虹 | 約 0.9～1.4 |
| 月球、環形星球、糖果星球 | 約 0.8～1.6 |

這些倍率只供程式配置，不寫入生圖描述。

### 主場

| 項目 | 設計 |
|---|---|
| 內容 | 火箭主角、金黃色星星、緞帶禮物盒、壞壞炸彈、被炸掉後可撿回的星星 |
| 動態 | 火箭固定於畫面下方偏中並左右移動；掉落物由上往下移動並輕微左右搖擺 |
| 素材 ID | CH001～CH012、IT001、IT002、OB001 |
| 分層作用 | 承載所有主要操作、收集與碰撞判定 |
| 視差速度 | 掉落物為速度基準 1；衝刺時整體加速，但炸彈仍保留完整預告距離 |
| 遮擋規則 | 主角與掉落物永遠顯示在中景前方，任何背景景物不得蓋住它們 |

火箭依高度進度切換三組固定配色，每組都包含四種狀態：

| 高度階段 | 直飛 | 傾斜轉向 | 被炸暈 | 衝刺 |
|---|---|---|---|---|
| 初始至第 19 顆全新星星 | CH001 | CH002 | CH003 | CH004 |
| 第 20～39 顆全新星星 | CH005 | CH006 | CH007 | CH008 |
| 第 40 顆全新星星以後 | CH009 | CH010 | CH011 | CH012 |

傾斜轉向素材只畫一側，另一側由程式水平鏡像。三組配色以整張素材切換，不使用程式染色，避免臉部、窗戶與尾焰一起被染色。

以火箭主體高度為 1 的程式排版參考：

| 主場元素 | 相對高度 |
|---|---:|
| 金黃色星星 | 約 0.22～0.26 |
| 緞帶禮物盒 | 約 0.26～0.32 |
| 壞壞炸彈 | 約 0.28～0.34 |
| 火箭 | 1 |

星星、禮物與炸彈保持三種完全不同的剪影與色彩：星星是金黃色圓角五角形，禮物是亮色方盒與大蝴蝶結，炸彈是深藍灰色圓球與橘黃引信。炸彈同時最多一顆。

### 前景

| 項目 | 設計 |
|---|---|
| 內容 | 發射煙雲、爆炸雲、暈星環、煙火、彩虹緞帶、冰淇淋、小狗、程式粒子與衝刺速度線 |
| 動態 | 短暫位移、縮放、旋轉、彈跳、淡入淡出或複製成小隊；演出結束後立即回收 |
| 素材 ID | FX101～FX107；部分表演重用 IT001、FX002、FX005 |
| 分層作用 | 強化發射、收集、撞擊、禮物驚喜與高度慶祝 |
| 遮擋規則 | 可以短暫經過火箭周圍，但不得長時間遮住掉落物生成區與炸彈預告 |

前景特效的使用原則：

- `FX101` 可複製成數朵圓煙雲，用於發射與火箭打嗝秀。
- `FX102` 在炸彈碰撞點快速放大後消失，不使用寫實火焰、黑煙或紅色受傷覆蓋。
- `FX103` 繞著暈臉火箭旋轉，與整支火箭翻滾方向刻意不同，形成笑點。
- `FX104` 可改變縮放、旋轉與位置組成煙火慶祝，但素材本身不由程式隨機染色。
- `FX105`～`FX107` 只在禮物盒事件中出現；表演期間暫停新炸彈生成。
- 衝刺速度線、炸彈紅色警告、星星閃點與細小彩帶粒子全部由程式繪製，不畫進素材。

### HUD

| 項目 | 設計 |
|---|---|
| 內容 | 星星持有數、高度路線、目前世界圖示、體感或手指教學圖示、護眼覆蓋層、追蹤暫失提示 |
| 動態 | 固定在畫面邊緣；數值與圖示切換時使用彈跳、點亮與短暫放大 |
| 素材 ID | 無，使用 HTML、CSS、Canvas 向量圖示或清楚的介面 emoji |
| 分層作用 | 告知大人目前狀態，並讓不識字的小玩家從圖示看懂方向與進度 |
| 遮擋規則 | 永遠位於最上層，但中央操作區保持乾淨 |

HUD 配置：

- 星星持有數固定在左上角，使用大星星圖示加繁體中文數值。
- 高度路線固定在右側，依序顯示城市、雲朵、彩虹、星球與月球五個大圖示。
- 高度路線只依「累積取得的全新星星」前進，不因撞炸彈掉星而倒退。
- 星星持有數可下降，與高度進度分開更新。
- 體感模式的左右移動與雙手高舉圖示只在教學或長時間沒有輸入時出現。
- 手指模式使用拖曳軌跡與雙指按住圖示，不改變遊戲世界的構圖。
- 護眼覆蓋層可在任何狀態凍結並蓋住整個畫面；解除時先清除炸彈，再恢復捲動。

## 二、各遊戲狀態的畫面

### 發射序曲

遠景使用明亮藍天。`BG001` 填滿畫面下半部，火箭以目前配色的直飛素材停在發射位置，正面朝向鏡頭。

倒數數字由程式在中央逐一顯示，火箭隨倒數輕微左右探頭。畫面兩側用大箭頭示範左右移動，但箭頭不遮住火箭的眼睛與臉。

發射瞬間複製數朵 `FX101`，由火箭底部向左右膨脹；火箭短暫上彈、畫面震動，`BG001` 快速向下離場。發射過程不生成炸彈、星星或禮物。

### 糖果城市上空與無文字教學

遠景使用明亮天藍色，`BG002` 位於中景下方，熱氣球 `FX002` 與小鳥 `FX003` 從兩側緩慢下降。

火箭先使用 `CH001`。前兩顆 `IT001` 固定出現在火箭附近並左右交替，讓小玩家在自然晃動中成功接到。火箭移動時切換 `CH002`，朝另一側移動時水平鏡像。

第一顆星出現時，程式箭頭示範左右移動；接到第二顆星後顯示雙臂高舉圖示，並讓火箭短暫切換 `CH004` 示範大火焰。沒有完成動作也不會停止流程。

累積取得第 5 顆全新星星後，`OB001` 才能首次從畫面上方出現。

### 一般飛行共同構圖

火箭固定在主場下方偏中，左右移動不改變垂直位置。`IT001`、`IT002`、`OB001` 從主場上方進入，並維持清楚的前後順序。

約七成有益物件出現在火箭附近容易接到的範圍，約三成出現在較遠的左右位置。背景朋友走畫面兩側，中景大型景物與主場掉落物錯開。

火箭沒有輸入時使用直飛素材；快速左右移動時切換傾斜素材；雙手高舉時切換衝刺素材。所有掉落物離開畫面後直接回收，漏接不顯示失敗訊息。

### 鬆軟雲海

累積取得第 10 顆全新星星後進入本層。`BG002` 向下離場，遠景轉為明亮青藍，數個不同大小的 `FX001` 從上方分批進入，形成前後錯落的雲海。

`FX002` 從較遠處慢慢下降，`FX003` 偶爾從側邊飛過。雲朵避免排成水平牆，也不遮住火箭正上方的掉落物路徑。

轉場結束後恢復正常生成。第 10 顆星的煙火使用 `FX104`，火箭仍維持初始配色。

### 彩虹高空

累積取得第 20 顆全新星星後，遠景轉為亮青色到純淨藍色，`FX004` 從上方緩慢進入中景，少量 `FX001` 以較小尺寸表現稀薄高空雲。

火箭切換為第一次升級配色：一般飛行使用 `CH005`，轉向使用 `CH006`，被炸暈使用 `CH007`，衝刺使用 `CH008`。

彩虹只在中景出現，不與禮物事件的前景彩虹緞帶重疊。若 `FX004` 尚在畫面中，禮物事件抽到彩虹緞帶時先延後背景彩虹的下一次生成。

### 閃亮外太空

累積取得第 30 顆全新星星後，遠景轉為明亮深寶藍星空，程式小星點開始緩慢向下移動。轉場不使用漆黑背景，也不加入陰森空洞區域。

`FX007` 從中景側邊緩慢下降，`FX005` 偶爾左右搖擺並向火箭打招呼。飛碟與星球尺寸大、速度慢、位置靠側邊，與主場的小型掉落物保持明顯差異。

火箭維持第一次升級配色，掉落物規則不變。

### 月球與糖果星系

累積取得第 40 顆全新星星後，遠景維持深藍但提高青藍亮度，`FX006` 與 `FX008` 成為代表景物，`FX007` 可作為較少出現的遠方星球。

火箭切換為第二次升級配色：一般飛行使用 `CH009`，轉向使用 `CH010`，被炸暈使用 `CH011`，衝刺使用 `CH012`。

月球與糖果星球不可同時擠在中央；一顆位於較高且較遠的位置，另一顆從相反側緩慢通過。畫面始終保留清楚的主場掉落通道。

### 高度轉場

第 10、20、30、40 顆全新星星都觸發高度轉場。

轉場開始時立即停止生成炸彈並清除畫面上的 `OB001`；現有星星與禮物可以繼續安全下降，但暫停碰撞懲罰。遠景平滑換色，舊高度代表景物向下離場，新高度代表景物從上方進場。

`FX104` 在畫面兩側綻放，高度路線的下一個圖示放大並點亮。火箭保持主場中央可見，不被煙火遮住。轉場結束後自動恢復飛行，不顯示確認按鈕。

若小玩家在轉場時雙手高舉，觸發火箭打嗝秀：一般衝刺暫停，火箭先切換衝刺素材並努力噴火，接著由程式把整支火箭壓扁再彈回，底部噴出一朵 `FX101`。事件不影響高度、星星或轉場結果。

### 衝刺

雙手高舉或手指模式雙指按住時，火箭立即切換當前配色的衝刺素材 `CH004`、`CH008` 或 `CH012`。

掉落物與背景捲動速度平滑加快，程式速度線從畫面上方向下掠過。星星生成密度提高，但畫面同時可見的炸彈數量仍不超過一顆，炸彈也不會突然生成在火箭正前方。

放下雙手、追蹤暫失或放開雙指後，速度線淡出，火箭平滑回到直飛狀態。

### 禮物盒驚喜

火箭接到 `IT002` 後，禮物盒快速放大並彈跳，接著抽取一種短表演。表演期間暫停新炸彈生成，既有炸彈先清除。

| 表演 | 畫面 |
|---|---|
| 彩虹緞帶 | `FX105` 從禮物盒位置彈出，繞火箭一圈後淡出 |
| 冰淇淋風暴 | 複製數個 `FX106`，從畫面兩側分隊上下跳舞 |
| 玩具小狗繞行 | `FX107` 沿火箭外圍跑一圈，由程式水平鏡像改變方向 |
| 熱氣球巡遊 | 複製 `FX002` 排成前後錯落的小隊，從中景兩側經過 |
| 外星朋友 | `FX005` 從側邊進入，左右搖擺並短暫停在中景打招呼 |
| 金色星星雨 | 複製較小的 `IT001` 從上方成群落下，降低透明度且關閉碰撞，不影響持有數與高度 |

表演結束後先留出安全空檔，再恢復炸彈生成。

### 炸彈警告與碰撞

`OB001` 從畫面上方出現時，程式在它外圍繪製清楚的紅色閃爍警告；素材本身不帶光暈。炸彈使用深色圓形剪影與橘黃引信，任何高度層都保持同一造型。

碰撞時依序播放：

1. `OB001` 先由程式橫向鼓起。
2. 炸彈消失，碰撞位置出現快速放大的 `FX102`。
3. 火箭切換成當前配色的暈臉素材 `CH003`、`CH007` 或 `CH011`。
4. 整支火箭旋轉三圈，畫面誇張震動。
5. `FX103` 繞著火箭旋轉，方向可與火箭相反。
6. 程式隨機加入壓扁彈回、倒噴小煙或暈星走錯方向其中一種笑點。
7. 最多三顆 `IT001` 從火箭附近彈出，之後向下飄，供小玩家撿回。
8. 火箭閃爍進入短暫無敵，再自動恢復正常飛行。

碰撞不顯示紅色受傷畫面、不播放哭泣表情，也不會中止遊戲或降低高度進度。

### 每十顆煙火與火箭升級

每取得十顆全新星星，畫面兩側以 `FX104` 組成煙火，HUD 星星圖示彈跳，高度路線同步點亮。

第 20 顆與第 40 顆除了煙火外，還會切換完整的火箭素材組。換色採用短暫縮小、彈回與閃白輪廓的程式動畫，不使用素材染色，也不改變火箭的比例、臉部或零件位置。

慶祝期間停止生成炸彈，煙火避開中央主場。

### 宇宙大巡遊

取得第 50 顆全新星星時，進入宇宙大巡遊。遠景維持月球與糖果星系色調，`FX006`、`FX007`、`FX008` 分批從不同深度通過，`FX005` 在中景搖擺致意。

`FX104` 在畫面兩側綻放，較小的 `IT001` 形成無碰撞星星雨；火箭短暫使用 `CH012` 衝刺穿過巡遊中央。所有背景朋友保持錯落，不排成同一條水平線。

巡遊結束後不出現結算畫面或重新開始按鈕，直接進入無限宇宙旅程。

### 無限宇宙旅程

第 50 顆全新星星以後，維持月球與糖果星系。`FX006`～`FX008`、`FX005` 依限制隨機搭配，每次只讓一至兩個大型星體同時在畫面中。

每再取得十顆全新星星重播煙火慶祝；每二十顆依初始、第一次升級、第二次升級的順序循環切換整組火箭素材。玩法速度不持續無限上升，避免最後失去反應時間。

### 護眼暫停與恢復

護眼機制觸發時，所有背景、掉落物、火箭、轉場與前景特效原地凍結，HUD 顯示全螢幕覆蓋層與倒數。

恢復前移除所有 `OB001`、取消炸彈警告並重設炸彈生成間隔。星星與禮物從安全位置繼續下降，火箭先回到直飛狀態，再恢復玩家輸入與世界捲動。

### 體感追蹤暫失

短暫遺失追蹤時，火箭保留最後安全的左右位置並退出衝刺，世界可以繼續以一般速度飛行。

持續遺失時，HUD 顯示大尺寸玩家輪廓與回到鏡頭範圍的圖示，畫面不生成新炸彈。重新取得追蹤後先清除既有炸彈，再讓火箭平滑跟隨新的身體位置，避免瞬間跳動。

## 三、色彩與光線

全案畫風為立體卡通 CG 渲染，像上了亮漆的塑膠玩具公仔；造型圓潤沒有稜角，無黑色描邊，色彩飽和明亮，使用柔和頂光。角色與景物依 `REF001.png`、`REF002.png` 與 `REF101.png` 統一造型、配色與世界高度關係。

`REF101.png` 作為由城市到糖果星系的世界縱剖基準，所有高度層遵守同一方向的柔和頂光與由遠到近的色彩層次。

| 高度層 | 遠景主色 | 中景重點色 | 主場對比策略 |
|---|---|---|---|
| 發射台／糖果城市 | 亮天藍、湖水藍 | 奶油白、珊瑚橘、亮青藍、向日葵黃 | 金黃色星星與深藍灰炸彈都能清楚辨識 |
| 鬆軟雲海 | 明亮青藍、偏白天空藍 | 白色、淡藍灰、橘黃 | 白雲降低對比並置於中景，星星保持高彩度 |
| 彩虹高空 | 亮青色、純淨藍 | 紅、橘、黃、綠、青的簡化彩虹 | 彩虹不穿過掉落物區，避免多彩背景干擾禮物盒 |
| 閃亮外太空 | 深寶藍、鈷藍 | 亮青、奶油黃、橘黃 | 不使用純黑；炸彈以紅色程式警告與橘黃引信維持辨識度 |
| 月球與糖果星系 | 深藍、明亮青藍 | 奶油黃、亮青綠、橘黃、紅色 | 大型星體降低對比並靠側邊，主場掉落物維持最高對比 |

光線規則：

- 所有圖片素材使用一致的柔和頂光與簡單分階陰影。
- 不在素材中畫投影、背光圈、發光邊緣、星芒或速度光線。
- 遠景不計算寫實光影，只用顏色明度建立高度變化。
- 中景越遠越偏冷、越淡、對比越低；主場角色與掉落物保持高飽和、高對比。
- 火箭三套配色只改外殼與尾翼，奶油白臉部、眼睛、窗戶、五官位置與橘黃色尾焰保持一致。
- 炸彈警告、煙火亮點、速度線與星空閃爍由程式繪製，不要求素材自帶光效。
- 本款沒有需要每局以程式隨機染色的圖片素材；所有素材使用固定上色。

## 四、每局的隨機變化

| 項目 | 可隨機變化 | 固定限制 |
|---|---|---|

| 無限旅程 | 背景朋友、星體、禮物事件與煙火組合 | 不增加新的操作規則，也不讓速度無限提高 |

每局隨機變化只改出場順序、位置、縮放、鏡像與表演抽選，不改角色造型、素材配色、五官、配件或高度層的主色。所有同組火箭影格必須保持一致。
