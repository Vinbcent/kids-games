# 🎅 遊戲10 聖誕老人送禮去

平安夜的深夜，全家都睡了：**在屋頂左右走，用大袋子接住掉下來的禮物 → 走到煙囪旁 → 揮手一件一件把禮物丟下去 → 禮物滑過煙道，大的放在聖誕樹旁、小的掉進掛著的襪子裡**。
屋主留了牛奶和餅乾，蹲下就可以偷吃一口（馴鹿的份是紅蘿蔔）。從頭到尾**沒有人醒來**——小朋友和阿嬤只會在夢裡笑一下、翻個身。

| | |
|---|---|
| 玩家 | 5 歲，不識字 |
| 體感訊號 | 身體左右移動（走位接禮物、走到煙囪旁）／**揮擲**（丟禮物、趕走屋頂貓與麻雀、空袋時空揮出糗）／蹲下（壓大熊進袋、鑽過晾衣被、偷吃餅乾、沒事就翻滾） |
| 揮擲怎麼判 | 讀**手腕相對肩線的上升速度尖峰**（時間性偵測，同遊戲5），不是單格姿勢；兩腕的尖峰合併，不會一揮丟兩件；有 0.55 秒冷卻 |
| 觸控備援 | 拖曳畫面＝走位；點「🎁 丟禮物」＝丟一件；點「🧎 蹲下」＝蹲 |
| 一袋四件 | 一次揮擲丟一件，四件要丟四次（輸入比「整袋一次送出」多三次） |
| 站太遠 | 不會失敗：禮物飛一半掉回來、輕輕頂一下肚子，再自己補送進煙囪 |
| 八段推進 | 每兩袋加一項新東西：禮物盒 → 玩具車／麵包紙袋 → 阿嬤家第二座煙囪 → 大熊卡袋 → 屋頂貓 → 晾衣被 → 麻雀 → 整條街的回禮 |
| 零挫折 | 沒有分數、扣血、重試或 Game Over。漏接的禮物會彈起來自己進袋；任何一段超過約 5 秒沒動作，畫面就自己慢慢演完 |
| 結局 | 屋主回送一隻大熊：蹲下讓牠坐上肚子（四腳朝天），揮一下兩個一起彈起來 |

## 場景

側視 2D Canvas，六層縱深（遠景 0.18 ／中景 0.5 ／屋頂主場 1.0 ／室內剖面 1.0 ／街道 1.0 ／前景盆栽 1.15）：

- **上層屋頂**＝玩家操作區，左側停著雪橇與馴鹿
- **中下層室內剖面**＝目標：煙道、聖誕樹與樹旁空地、掛襪、床上熟睡的住戶、床頭矮櫃上的牛奶餅乾
- **最下層**＝台灣街景：平屋頂、水塔、鐵皮加蓋、騎樓、機車、紅磚人行道、聖誕紅

全程是深夜，但**不把畫面壓成黑底亮燈**；燈串只有不發光的實心小圓點。

## 開發

- 企劃 `plan.md`、場景 `scene.md`、素材清單 `assets.json`（34 張素材＋7 張設定圖）
- 測試勾子：`__art()` 列出載不到的素材、`__step(秒, {toss, squat, x})` 手動快轉、`__sim()` 自動玩完十六袋（`__sim(4,{lazy:true})` 完全不操作，驗證援助不會卡住）
