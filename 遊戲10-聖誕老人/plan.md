# 遊戲10-聖誕老人 企劃

## 一、一句話說明

小玩家化身圓胖的聖誕老人，在平安夜的台灣街屋屋頂左右走動，接住**麋鹿拉著飛行雪橇送下來的四件禮物**，再揮動手臂，**一次丟出一件，四次丟完一袋**；禮物沿著清楚的弧線進入矮胖紅磚煙囪，滑到樓下聖誕樹旁或掛著的襪子裡。兩戶小朋友全程躺著熟睡，屋頂偶爾出現丟炸蛋的搗亂小精靈，讓聖誕老人原地轉圈。每完成兩袋，聖誕老人搭上低空懸停的雪橇，前往下一處屋頂。

**最高設計原則：每隔一小段時間，就讓小玩家發現一件新的事，而且看得懂事情從哪裡來、往哪裡去。**

整款保留「接滿一袋 → 丟完一袋」的循環，不另開小遊戲、不增加第四個訊號。變化來自禮物、兩間住家、屋頂路線與搗蛋事件逐步加入。

一輪共八段街區、十六袋禮物。每袋四件，正常手動完成需要四次投擲，全輪共六十四次送禮投擲。一般主動遊玩約五至六分鐘，沒有倒數、扣分、生命值或 Game Over。

本版畫面與流程固定如下：

- 禮物由空中的麋鹿雪橇送下來，每件都從雪橇貨艙口連續離開，不憑空出現在畫面上緣。
- 屋頂操作區成為畫面主角；室內縮成約占畫面高度兩成的淺帶。
- 移除馬路、機車、人行道與聖誕紅盆栽，畫面下緣以住宅基座收住。
- 煙囪使用矮胖入口，另接簡單的開放滑道；室內使用乾淨的住宅剖面單體，減少零碎佈景。
- 兩戶住戶都是熟睡的小朋友：CH303 黑短髮男孩、CH304 綁髮女孩，躺在 TP014 自帶的床上；收禮區在床的對面那一側。
- 移除蹲下偷吃餅乾與餵麋鹿紅蘿蔔的整段流程，IT006 点心餐盤退出。送完一袋直接接下一袋；每段第二袋送完照常換場，最後一袋接結局。
- 第五段加入搗亂小精靈，第七段與麻雀輪流出現。接到炸蛋是轉圈笑話，不扣禮物或進度。

故事始終是**平安夜深夜**。男孩與女孩都躺著、閉眼，沒有人看見聖誕老人。安靜是故事氣氛，不是要求小玩家保持不動；不偵測音量，也不設吵醒懲罰。

本版以飛行雪橇取代屋頂常駐停靠。小玩家仍在屋頂工作，飛行、懸停、登乘與換場都是故事演出，不增加駕駛操作。

## 二、玩法核心

### 操作動作

全程只用三個白名單訊號：**身體左右移動、揮擲、蹲下**。不偵測手指，不要求跳躍，也不要求左右手分工。

**揮擲讀取手腕相對肩線的上升速度尖峰，是一小段時間內的速度判定，不是單格姿勢辨識。**

| 體感訊號 | 接禮物階段 | 送禮物階段與送達後 | 手指模式 |
|---|---|---|---|
| 身體左右移動：肩膀中心水平位置 | 聖誕老人沿屋頂走位，用袋口接住飛行雪橇送下的禮物；小精靈出現時也可靠近炸蛋落點看笑話 | 移到本袋目標住家附近；投擲自動瞄準。送達後準備下一袋或自動換場 | 在操作區左右拖曳；放開後保留位置，本袋目標不變 |
| 揮擲：手腕相對肩線的上升速度尖峰 | 有小精靈、貓或麻雀時空手趕走牠；沒有干擾者時做空手笑話，不提前送出未滿袋的禮物 | 每揮一次丟出一件；空袋時空揮出糗。結局觸發彈熊，完成畫面觸發重玩 | 點一下「丟」大圖示按鈕；按住不連發，放開再點才是下一次 |
| 蹲下：身高相對站姿基準的比例下降 | 大熊卡袋時壓進袋裡；沒有特殊情境時自由翻滾 | 被子擋路時縮身通過；其他時間翻滾。結局可接熊 | 點一下「蹲下」大圖示按鈕；通過被子時可按住 |

飛行雪橇自動工作。小玩家不用抬手叫它、不用瞄準它，也不用站到雪橇正下方才允許落物。

**蹲下只有四種操作意義：壓大熊進袋、鑽過晾衣被、沒事就翻滾、結局接熊。** 登乘或結局沿煙道往返時使用的蹲姿是自動演出，不是額外的蹲下任務。

**一次動作只處理一件事**

1. 已觸發的短動作演出期間，不接受第二個姿勢事件，也不把輸入排隊帶到下一階段。
2. 蹲姿成立時，優先執行目前明確啟用的蹲下用途；半蹲揮手不會同時投擲。
3. 揮擲成立時，短暫保留人物位置與本袋目標，連播預備、出手兩格。
4. 出手短動作結束後恢復走位；前一件進入煙道後，就可準備下一投，不必等室內完全落定。
5. 其他時間以左右移動控制走位。

三個身體訊號在現實中可能同時出現，遊戲將它們處理成互斥行為，不要求小玩家同時走位、蹲下與投擲。

同一次揮動中，兩腕先後出現的速度尖峰合併為一個事件。觸發後有短冷卻，速度回落、離開觸發區後，才接受下一次新揮擲；不要求手必須回到腰間或指定位置。身體上下晃動本身不當成投擲。

蹲下在進入蹲姿時觸發，站回來才準備下一次，保留冷卻與遲滯緩衝。持續蹲著不會連續翻滾或接熊。

**訊號的情境用途**

| 情境 | 操作與畫面 | 衝突隔離 |
|---|---|---|
| 接取時，小精靈正在搗亂 | 揮擲，聖誕老人空手甩臂，把小精靈趕走 | 不消耗袋內禮物；此時尚未開放送禮 |
| 接取時，貓占袋口或麻雀叼禮物 | 揮擲，聖誕老人空手甩臂，動物誇張後仰讓開 | 不消耗袋內禮物；此時尚未開放送禮 |
| 接滿後，袋內仍有禮物 | 每揮一次丟一件，四次丟完 | 剩一至三件仍屬送禮階段，不返回接取 |
| 空袋，或接取時沒有干擾者 | 空揮後轉一圈、站穩裝作沒事 | 不生成假禮物，不消耗已接物，不重設援助 |
| 大熊卡袋 | 蹲下，熊與袋子壓扁一下再回彈 | 暫停下一件釋放，不同時翻滾或投熊 |
| 晾衣被擋路 | 蹲下，人物與袋子短距離滑過 | 只在送禮走位段啟用，通過後才接受投擲 |
| 沒有特殊蹲下用途 | 蹲下翻滾，四腳朝天吐舌頭 | 不扣進度，特殊用途啟用時不疊加 |
| 結局 | 蹲下接熊坐肚子；揮擲讓人物與熊一起彈起 | 結局接管用途，不再投普通禮物 |
| 完成畫面 | 新的一次揮擲開始重玩 | 必須先讓前一個動作回落，不能沿用結局事件 |

蹲下判讀順序固定為「**當前特殊情境 → 自由翻滾**」。各特殊情境由不同階段隔開，畫面一次只示範一種用途。

小精靈、貓、麻雀的「趕走」都使用同一個揮擲訊號，沒有新增第四個訊號。干擾事件與正式送禮的情境分開，同一次揮擲不兼做趕走和投禮物。

### 一局的流程

**前十秒：先看見來源，再開始接**

- 開場直接看見寬大的屋頂操作區，聖誕老人站在空袋旁。下方淺室內帶有聖誕樹、掛襪與床上熟睡的小朋友。
- 麋鹿拉著雪橇從畫面左側飛入上方航帶。聖誕老人已在屋頂，不先播下車過場。
- 第一件方盒先露在雪橇貨艙口，跟著雪橇移動一小段，再從同一個位置落下。
- 第一件落點安排在袋口附近；第二件引導一小步移動。
- 每接到一件，袋子短短鼓一下。雪橇內下一件露出輪廓，讓小玩家知道還有禮物。
- 滿袋後停止供禮，雪橇移到上方側邊懸停；箭頭改指屋頂煙囪，示範揮擲。
- 第一揮只丟出一件，另外三件仍留在袋裡。
- 第一件沿弧線進入矮煙囪，接上可見滑道，再落到室內樹旁；第一次先完整展示這條路徑。
- 若一直沒有推進，援助逐件接滿、逐件投出，不把教學變成入口關卡。

前十秒的目標是看懂「雪橇送來 → 左右接取」，並開始理解第一次投擲；不是要求十秒內完成四次投擲。

**飛行供禮：一組隊伍，一趟往返四件**

使用**一隻麋鹿拉一台雪橇**的固定飛行隊伍。單隻大鹿角、細腿與雪橇彎滑板足以交代故事，也避免多隻鹿縮成細碎輪廓。

麋鹿與雪橇固定相連、永遠一起移動，使用一張飛行隊伍素材。禮物、聖誕老人、禮物袋與結局回禮熊保持獨立。

| 項目 | 設計 |
|---|---|
| 進場 | 每段第一袋由畫面左側進入，朝右飛；先看見整隊，再釋放第一件 |
| 飛行高度 | 一般供禮位於畫面上方約 9～25%；貨艙釋放口約在 22～26%，低於 HUD、高於人物帽尖 |
| 基本路線 | 畫面內短程往返，去程向右送兩件，回程向左送兩件；四件是一袋，不飛到畫外繞大圈 |
| 轉向 | 第二件下降時完成減速、水平鏡像與回程；不畫轉身背面，不整隊翻筋斗 |
| 一趟件數 | 固定四件；漏接補回仍是原物件，不另掉第五件 |
| 飛行速度 | 隨下一個可達落點調整，不以固定高速掃過整個畫面 |
| 袋滿後 | 停止供禮，移到上方側邊懸停，把注意力留給投擲 |
| 下一袋 | 利用前袋投擲、送達時間先就位，接取開始時即可釋放第一件 |

「往返」描述方向變化，**不要求每袋橫跨整個螢幕兩次**。轉向點依已安排的落點調整；小玩家留在中央時，雪橇可以在中央上方完成較短的往返。

一般供禮時，隊伍與下一件禮物保持完整可見。首次進場不在半台雪橇還藏在畫外時就落物。

**落點必須對得上雪橇**

每件禮物的順序固定：

1. 先決定一個小玩家可達的接取位置。
2. 雪橇飛到能自然送往該位置的上方。
3. 待送禮物露在貨艙口，與雪橇一起移動；這是同一件禮物，不是另畫一份裝飾。
4. 到達釋放位置後，禮物從貨艙口離開，向下落入接取區。
5. 入袋、卡袋或漏接補回，都接續這一件，不換圖、不複製。

禮物下降以接近垂直為主，只保留少量、平緩的水平延續。雪橇不必靠高速拋物把禮物甩到另一邊。

**真正的落下起點是雪橇貨艙口，不是畫面上緣，也不是事先選好的任意空中座標。** 隊伍鏡像後，貨艙口與待送禮物的位置一起改變，不能還從舊的一側掉出來。

落點約七成在目前袋口或一小步內，三成稍遠。這項安排在釋放前完成：

- 玩家突然走開時，已釋放的禮物不瞬間橫移追人。
- 寬鬆接取與漏接後的屋頂彈回負責接住偏差。
- 接近操作邊界時，下一件引回內側，不引導追到畫外。
- 第一件最容易，第二件再給小側步；不因雪橇行進方向而強迫玩家一路追著跑。

麋鹿與雪橇沒有獨立丟擲影格。禮物從開放貨艙的後下緣滑出即可，不新增會開關的艙門。

**不等雪橇飛回來**

一袋四件採連續接取：

- 第一件下降時，雪橇已在前往第二個釋放位置。
- 第二件下降與接取時，雪橇完成轉向，準備第三件。
- 第三件下降時，雪橇準備第四件。
- 第四件下降時，隊伍移往送禮階段的側上方待命位置。

一般釋放間隔以約兩秒為節奏參考，可依下降距離與可讀性放慢，不是倒數期限。畫面主要突出一件正在接近袋口的禮物，下一件可以露在貨艙口，或位於較高處；不讓四件同時落成一團。

**袋子容量包含已釋放、尚未入袋的待接物。** 已承諾的四件足夠完成本袋時，不再釋放額外物件，避免漏接補回與新落物同時把袋子塞過量。

小精靈投出的炸蛋不屬於這四件禮物，不占袋子容量、不填容量格，也不送進煙囪。

雪橇的回程、轉向與下袋就位都安排在現有接取或送達時間內。不能因為飛行路線還沒走完，就讓屋頂上的聖誕老人空等。

**什麼時候懸停**

空中隊伍可以懸停，但懸停必須服務正在進行的事情：

| 情境 | 雪橇行為 | 小玩家仍在做什麼 |
|---|---|---|
| 大熊卡住袋口 | 暫停新釋放，在上方保留下一件待送禮物 | 蹲下壓熊 |
| 貓占袋口 | 先停供禮，已有落物放緩或補接 | 揮擲逗貓 |
| 麻雀叼住已釋放的禮物 | 隊伍停在旁上方，不繼續往同一處倒禮物 | 揮擲讓麻雀鬆口 |
| 送禮階段 | 上方側邊安靜懸停，避開投擲弧線 | 走位與四次投擲 |
| 換場或結局登乘 | 整隊降低、停穩，滑板與屋頂保留可見空隙 | 自動登乘銜接 |

沒有「等麋鹿休息完」「雪橇繞回才能繼續」的獨立等待狀態。特殊事件解除後，下一件從已經在場的貨艙口接續。

空中懸停只做極小幅度的整隊起伏，沒有反覆彈跳、閃光或飛行粒子。

**兩階段循環**

| 階段 | 小玩家要做什麼 | 完成條件 | 即時回饋 |
|---|---|---|---|
| 接禮物 | 沿屋頂左右走，接住雪橇送下的四件；偶爾處理一項特殊事件 | 四件全部入袋，補接也算 | 每件從雪橇可見地落下，入袋後袋子鼓動 |
| 送禮物 | 靠近目標住家，揮擲四次，每次丟一件 | 四件全部進入本袋煙囪，抵達樹旁或襪內 | 袋內逐件減少，禮物沿完整路徑逐件送達 |

袋子固定四件。進入送禮後，剩三件、兩件或一件時仍是同一袋，不重新要求接滿，也不開放空中供禮。

最後一件出手後，可準備下一袋走位；等本袋四件全部送達才正式接續。飛行隊伍利用這段時間就位，不搶先把下一袋禮物掉下來。

本袋送達後不再出現點心入口、蹲下吃餅乾或餵麋鹿演出。第一袋完成直接接第二袋；第二袋完成接換場；第十六袋完成接結局。

**兩戶、兩座煙囪，不增加瞄準考試**

前兩段只有一個有效送禮目標。第三段起，兩座矮煙囪各自連到下方一間住家。

| 住家 | 主要辨識 | 固定關係 |
|---|---|---|
| 男孩家 | CH303 黑短髮小圓頭、霧藍袖口、奶油暖灰被子；睡眠角落在房間一側 | 男孩始終躺在 TP014 自帶的床上，收禮區在床的對面那一側 |
| 女孩家 | CH304 腦後外露的粗髮束、柔和橢圓臉、淺土褐睡衣、灰綠被子；家具排列與另一戶相反 | 女孩始終躺在鏡像 TP014 自帶的床上，收禮區在床的對面那一側，煙道不與另一戶交叉 |

每袋只提示一座煙囪，四件全部送往同一戶。目標由段落決定，左右移動不改變本袋收件住家。

第三段兩袋固定先送男孩家、再送女孩家。之後可交換順序與整戶左右位置；住戶、床位、樹旁空地與煙道必須一起交換。

住戶不醒來、不伸手指示，也不靠文字姓名辨識。目標提示使用安靜的實心箭頭。CH403 阿嬤退出本版，不在其他住家或結局出場。

**揮出去就送到**

每次有效揮擲，聖誕老人連播：

- CH007：手臂往後拉的預備姿。
- CH008：手臂向前上方甩出的出手姿。

這兩格是人物表演，不要求小玩家先做預備動作。

同一件禮物從袋口移到手邊，再離手飛往煙囪。袋子留在身旁，只輕鼓一下；不托起整袋、不一次倒出四件。

揮動幅度不控制力度或距離，手腕位置不控制準度。每次新揮擲成立，就自動送出一件。

前件進入煙道後，下一件可以出手；不等待整條送達路徑播完。過快連揮不排成延後執行的長佇列。

**站遠了：肚子幫忙彈一下**

明顯站得太遠或站在另一戶附近時，每袋最多讓第一件演一次短笑話：

1. 禮物離手後在人物附近輕折回。
2. 輕頂圓肚子，聖誕老人後縮一下。
3. 同一件禮物接上第二段柔軟弧線，準確進入本袋煙囪。
4. 後面三件直接自動修正送達。

不要求補揮、不扣進度，也不必走回某個窄小定點。一般位置偏差直接寬鬆送達，避免每袋都拖長。

笑話在煙囪入口之前完成；禮物進入滑道後不折回屋頂、不穿到另一戶，也不碰睡著的人。

**矮煙囪與完整送達路徑**

本版煙囪分成兩個用途明確的部分：

- 屋頂上的**矮胖紅磚入口**，是投擲目標。
- 入口下方的**開放剖面滑道**，是眼睛追蹤禮物的路徑。

兩件在場景裡固定相接，屬於同一戶，不獨立漂動。

每件送達順序：

1. 袋內取出。
2. 經過手邊，沿弧線進入矮煙囪。
3. 從入口直接接上樓板下方可見滑道。
4. 沿短而寬的通道下降。
5. 從室內出口接到樹旁或襪口。
6. 到位後做一次小回彈或搖晃，留下可辨認輪廓。

禮物在煙囪、樓板、滑道與室內出口交界都不能突然消失。入口前側與滑道前方保持開放，讓小玩家一直看得到原本那件禮物。

尺寸若因進入較小室內而調整，沿路平緩變化，不在樓板處突然縮小，也不把大熊擠成細線。

不增加大小分類、第二次瞄準或室內補投。

室內縮小後，不同時讓多件禮物在終點跳動。正在送達的那件最清楚，已到位的安靜留在旁邊。

**熟睡住戶**

男孩與女孩均使用真正的側躺睡姿，頭、軀幹與被子保持躺臥關係。不能把舊站姿旋轉成睡姿。

兩位住戶都放在 TP014 單體自帶的床面上，不另疊獨立床架。人物與被子可以一起微動，床、床頭矮櫃及房間結構保持固定。收禮區在床的對面那一側，禮物不經過孩子頭部或落到被子上。

雙眼永久閉合，嘴角帶夢裡的微笑。偶爾人物與被子整體窩動一下，床不動：

- 不坐起、不睜眼。
- 不伸手、不接禮物。
- 不跟每件送達同步反應。
- 不因漏接、翻滾、空揮或炸蛋轉圈而被吵醒。
- 不新增夢境泡泡、睡眠文字或睡眠量表。

在淺室內帶裡，重點是**清楚的頭部、水平被子與床面**，不靠手指、衣服細節或表情動畫交代熟睡。

**搗亂小精靈：兩顆炸蛋的小表演**

第五段首次登場，取代原本以屋頂貓為主的段落。第七段與麻雀分袋輪流出現，不在同一袋一起干擾。

小精靈使用 CH601 投擲預備、CH602 投擲出手兩張姿勢；炸蛋使用獨立 OB001。人物與炸蛋分開，同一顆炸蛋從手邊連續離開，不把道具畫死在人物手上。

事件放在接取階段，流程固定：

1. 小精靈站在離聖誕老人較遠的那一側，完整露出小個子輪廓。
2. 切 CH601，舉起一顆 OB001 炸蛋，讓小玩家先看見牠和道具。
3. 切 CH602，同一顆炸蛋離手，沿清楚的弧線丟向接取區。
4. 等 **2.4 秒**，再舉起並丟出第二顆。
5. 丟完兩顆，小精靈自己跺腳走人。

2.4 秒是兩次投蛋之間的演出間隔，不是要小玩家在期限內完成動作。**不理牠也不會卡住**，小精靈會自行結束表演離開。

小玩家可以在牠還在場時揮擲，把小精靈趕走。這與趕貓、趕麻雀是同一個操作意思，不消耗袋內禮物，也不把禮物拿來砸牠。趕走後停止牠尚未進行的投蛋；已離手的炸蛋照常完成接到或落地的短反應，不再補丟。

**炸蛋接到、沒接到都好笑**

| 結果 | 畫面 | 對進度的影響 |
|---|---|---|
| 接到炸蛋 | 聖誕老人原地轉兩大圈，身體微彈，撒幾點柔色星星 | 袋內禮物一件都不會少，不扣進度、不重來 |
| 沒接到炸蛋 | 炸蛋落在屋頂上，「噗」一聲洩氣 | 不扣進度，不要求撿回或補接 |
| 揮擲趕走小精靈 | 聖誕老人空手甩臂，小精靈離開 | 保留全部禮物與既有進度，接續原袋流程 |

接到炸蛋是好笑的獎勵，不是懲罰。小玩家可以故意走向炸蛋落點，只為看聖誕老人轉圈，也可以繼續接禮物或揮擲趕走牠。

炸蛋不造成爆炸、閃光、火焰、煙霧、碎片或受傷表情。原地轉圈不把人物甩出屋頂，不把袋內禮物撒出去，不增加生命值、扣血或重試畫面。

柔色星星只在接蛋轉圈時短暫出現，使用兩種柔和顏色、少量、稀疏，像安靜的玩具貼紙；不發光、不帶光暈、不爆閃，不新增特效圖片。

炸蛋靠**深色蛋形＋柔軟捲毛引線**的剪影分辨，與方盒蝴蝶結、玩具車、熊、紙袋和紅包都不同。深暖灰是第二層提示，不只靠顏色判斷。

炸蛋不是雪橇送來的禮物，不占四件容量、不增加送禮件數、不進袋留存，也不送往住戶。小精靈與大熊卡袋、貓、麻雀互斥；連同晾衣被事件，仍維持**一袋最多一項主要特殊事件**。

**空袋也能玩**

空袋時揮擲，聖誕老人連播預備、出手，接著腳下一滑，整個人轉一圈，再站穩裝作沒事。

接取階段沒有小精靈或動物干擾時也沿用此笑話；已在袋裡的一至三件保留，不能提前投出。

- 不生成假禮物。
- 不把炸蛋、屋頂或飛行隊伍當彈藥。
- 不清除飛行中或正在送達的禮物。
- 不重設援助計時。
- 單次以約一秒內恢復操作為目標，保留短冷卻。

沒有特殊用途時蹲下，仍可自由翻滾、四腳朝天吐舌頭。持續看笑話也會在援助下推進，不困在原地。

**每兩袋換場：雪橇低空接人**

每段兩袋完成後，飛行隊伍來接聖誕老人，不再回到一台常駐停放的雪橇。

1. 本段第二袋最後一件送達時，隊伍已移到屋頂一側上方，準備降低。
2. 隊伍在平台外側低空懸停，滑板與屋頂保留可見間隙。
3. 聖誕老人和空袋短距離移到雪橇旁，人物切蹲姿進入座位。這是自動登乘，不要求小玩家跳躍、蹲下或準確走到邊緣。
4. 隊伍、人物與袋子一起向右低空飛行，場景開始視差換場。
5. 到下一處屋頂，隊伍再次懸停，聖誕老人與袋子自動移到安全操作區。
6. 隊伍上升到供禮航帶，第一件禮物已露在貨艙口，隨即開始下一袋。

轉場是一段短銜接，不增加空中關卡。人物不跌落屋頂、不要求平衡，也不讓玩家追著飛走的雪橇。

接送人的空中隊伍與供禮隊伍是同一組。聖誕老人、袋子與熊始終獨立，不在換場時換成另一張含乘客的合成圖。

**操作密度與節奏**

普通循環以約十八至二十秒為目標，飛行供禮取代原本憑空落物，不額外增加等飛機的時間。

| 普通循環時段 | 內容 | 有效操作估算 |
|---|---|---:|
| 約八秒 | 雪橇往返供四件，左右接取 | 八秒 |
| 約一秒 | 滿袋回饋、切換目標提示 | 零秒 |
| 約兩秒 | 靠近目標住家 | 兩秒 |
| 約四秒 | 四次分開揮擲，前件入煙道與下一投準備重疊 | 最多四秒，須扣除實際強制等待 |
| 約一秒 | 最後一件進煙道，準備下一袋走位 | 一秒 |
| 約兩秒 | 剩餘禮物落定、銜接下一袋 | 零秒 |

在十八秒範例中，有效操作估算上限為十五秒，約 **83%**；這是設計估算，不是實測結果。不能把整段送禮或觀看飛行都算成身體操作。

普通循環約有九至十次有目的的操作：接取三至四次走位、靠近住家一次、四次投擲，以及下一袋準備一次走位。

雪橇轉向、下袋就位與換場接近，優先與正在進行的接取或送達重疊。若小玩家較慢，就讓雪橇調整或懸停，不用加快落物追趕表定節奏。

小精靈兩次投蛋之間的等待及接蛋轉圈屬於事件演出，不能全部算成有效身體操作。小玩家主動走向落點或揮擲趕走時，才計入對應操作。

十六袋約四分四十八秒至五分二十秒，加上首次示範、短換場、特殊事件與結局，一輪以五至六分鐘為目標。動作較慢或反覆看笑話時可以更長，沒有超時失敗。

實玩仍以**至少七成時間有有效身體操作**為目標。若不足，優先縮短出手鎖定與空中接人的停頓，增加各段自然重疊；不加速下墜來逼動作，也不額外插入等待段落。

首次介紹新內容時，暫停其他主要特殊事件。後段可選用已學內容，但**一袋最多一項主要特殊事件**；卡熊、小精靈、貓、麻雀與晾衣被互相排除。第七段的「輪流」是跨袋輪流，不在同一袋接連塞入兩個事件。

距離補送與空揮是一般操作的短回饋，不另外串成長關卡。

### 勝負與結束條件

**完成條件**

- 每袋四件、每段兩袋、八段十六袋，共六十四件。
- 正常手動送禮每件揮擲一次，共六十四次；趕小精靈、逗動物、空揮與結局不算送禮件數。
- 手動接到、漏接補回、援助投出與距離補送都算正常進度。
- 第十六袋四件全部落定才進入結局，不在最後一件離手時直接結算。
- 炸蛋不算禮物，不占容量、不增加或扣除件數及袋數。
- 接到炸蛋只演好笑的轉圈，袋內禮物不減少，不要求重接或重投。
- 沒有 Game Over、生命值、重試、倒數或保持安靜的要求。

**大結局：低空雪橇接走聖誕老人與回禮**

最後住家從抵達時，就在矮櫃旁放著一隻 IT003 回禮熊。位置與樹旁收禮區分開，表示屋主睡前預先準備，不是拿回剛送出的玩具。矮櫃旁不放 IT006 餐盤。

1. 第十六袋全部送達，供禮結束。飛行隊伍在上方安靜等候，貨艙不再掉物。
2. 聖誕老人沿最後一座煙囪與滑道下去，自己發現矮櫃旁的熊。旁白交代這份是給聖誕老人的。
3. 人物和熊沿可見原路返回屋頂，原位置不留下熊的副本。
4. 熊停在人物面前，恢復較大的互動份量；小玩家可左右靠近。
5. 蹲下時，人物縮成一團，熊輕輕坐到圓肚子上，聖誕老人四腳朝天吐舌頭。
6. 揮擲時，人物做預備、出手，自己和熊一起短短彈起，再落回屋頂。沒有先蹲也能直接演這段。
7. 笑話期間，隊伍降低到屋頂外側懸停。熊從屋頂短距離移入雪橇，聖誕老人接著登乘。
8. 麋鹿拉著雪橇緩緩升高、向右飛，帶走聖誕老人、袋子與回禮。

熊和人物先安穩落回屋頂，再自動登乘；不要求用揮擲把熊準確丟進飛行雪橇。

互動笑話以約八秒為目標，發現、登乘與出發各用短銜接。約五秒沒有推進，援助接續完成，不要求一定依序蹲、揮才能結束。

小精靈的事件已結束，不在結局追加投蛋。貓與麻雀留在原屋頂。下方住戶仍閉眼躺睡，不歡呼、不合照、不向天空揮手。

完成畫面保留上方完整可見的飛行隊伍、聖誕老人與熊，緩緩懸停；下方仍是安靜住宅。只顯示一顆「再送一次」大圖示。

體感模式以新的一次揮擲重玩，手指模式點按。完成畫面先等待上一動作回落，避免結局的揮擲直接觸發重玩。

## 三、難度與挫折控制

**難度增加的是新鮮感**

- 禮物種類增加，接取範圍不縮小。
- 飛行路線服務可達落點，不要求追著雪橇跑。
- 禮物一定先從貨艙可見地離開，不從看不到的畫外突然落到頭上。
- 兩座煙囪增加走位差異，不變成住戶辨識或分類考試。
- 揮擲自動瞄準，不依幅度或手腕位置判定準度。
- 四次投擲沒有拍點、倒數或連續完成要求。
- 屋頂高低是連續安全路線，不需要跳躍。
- 縮小室內時減少裝飾，不縮小關鍵物件到難以辨認。
- 小精靈先舉蛋再投出，來源與弧線清楚；不要求精準閃避或反擊。
- 接到炸蛋只得到轉圈笑話，不損失袋內禮物。
- 不以加速、縮窄平台、增加同時落物或吵醒住戶提高難度。

**搗蛋角色**

| 角色 | 怎麼來亂 | 操作 | 不處理的後路 | 笑點 |
|---|---|---|---|---|

小精靈與炸蛋、動物與禮物都分開。聖誕老人沒有拿禮物砸干擾者，小精靈與動物不受傷、不恐慌。

小精靈、大熊卡袋、貓、麻雀互斥，並與晾衣被共用一袋一項主要特殊事件的上限。飛行隊伍不是搗蛋者，不叼走已接禮物，也不撞人。

干擾者退場後，原揮擲事件結束；若袋子已滿，要等新的揮擲才開始第一投。已離手的炸蛋仍只會轉圈或洩氣，不改變袋內禮物與送禮進度。

**五秒沒有推進，就自己接續**

援助看的是任務有沒有推進，不只是骨架有沒有動。反覆翻滾、空揮或左右亂晃，不能永久重設等待。

| 卡住位置 | 約五秒後的援助 |
|---|---|
| 不知道怎麼接 | 雪橇帶下一件靠近目前袋口上方，清楚釋放，逐件補接 |
| 一直接不到 | 放緩下降；漏接物在屋頂彈一次，自動回袋 |
| 飛行路線尚未就位 | 隊伍縮短路程、就近完成供禮，不等完整巡航 |
| 大熊卡袋 | 自動示範蹲下，把熊壓進袋子 |
| 小精靈在場而玩家不理牠 | 小精靈依自身兩次投蛋流程離開，不必等援助或成功趕走；援助接續原袋接送 |
| 貓占袋口 | 貓自己側倒讓開，隊伍接續供禮 |
| 麻雀叼住禮物 | 自行鬆口，原物件繼續入袋 |
| 滿袋不走位 | 自動靠近目標；若先揮擲，直接寬鬆送達 |
| 滿袋不投擲 | 示範一投，再逐件送完，不一次倒出整袋 |

| 被子擋路 | 整組衣架稍微抬高，人物縮身通過 |
| 一直翻滾或空揮 | 短笑話結束後接手補接、投擲或換場 |
| 換場沒有動作 | 自動登乘、飛往下一處屋頂、下車開始下一袋 |
| 結局沒有操作 | 自動完成接熊、彈起、登乘與出發 |

五秒是援助啟動等待，不是限時，也不要求整段動畫必須在第五秒瞬間結束。

連續無操作時，援助跨階段延續，不在每件禮物、每個動作或每次登乘重新等五秒。一般阻塞在援助開始後約二至三秒內解除；逐件投擲與結局以清楚可讀的節奏自行演完。

小精靈的兩次投蛋是會自行結束的短事件，不重開無限投蛋循環。接蛋轉圈不扣任務進度，也不因笑話反覆重設整袋任務。

小玩家重新做出有效操作，下一個可接手時點就恢復控制。已取得進度全部保留，不出確認視窗。

護眼暫停與追蹤中斷不算沒操作，不累計援助，也不在遮住畫面時偷偷推進。

| 觸發 | 畫面 | 進度 |

| 漏接禮物 | 禮物彈屋頂、輕頂屁股，再回袋 | 仍算接到 |

一般翻滾、空揮與補送笑話以約一秒內恢復操作為目標；炸蛋轉圈保留完整兩圈與微彈，結束就接回原流程，不增加確認或重試。接取期間的落物放緩或補接；已投出的禮物正常送達。

自由翻滾的蹲下訊號與一般左右接取、揮擲送禮錯開；特殊蹲下用途開放時不再翻滾。接蛋轉圈由接到炸蛋觸發，不另外占用姿勢訊號。

**護眼暫停與恢復**

依共用距離規則判定過近，顯示全螢幕覆蓋層並暫停五秒。飛行隊伍、待送禮物、下降、投擲、滑道送達、小精靈投蛋與間隔、炸蛋飛行、笑話、登乘、換場、結局與援助計時全部凍結。

解除採用**推回起點**，保留已取得進度：

- 尚未接到的一般落物，帶回其供禮起點。隊伍與同一件禮物先以短而可見的回收動作重新對上貨艙口，再慢慢釋放。
- 回收過程不另生成一件，也不恢復成任意畫面上緣落物。
- 若隊伍已有下一件待送，先暫停它，依原順序處理恢復中的物件。
- 干擾中的貓或麻雀回到事件起始位置，重新預告；麻雀事件的禮物仍是原件。
- 小精靈尚未落定的炸蛋回到其投出起點，重新保留舉蛋預告；同一顆只接續一次，不因此增加第三顆。尚未完成的投蛋間隔從暫停處接回。
- 已經觸發的接蛋轉圈或落地洩氣從原演出接續，不重複判定、不再扣除或重算任何禮物。
- 已入袋、已出手、已送達與完成袋數全部保留。
- 已出手禮物從原弧線或滑道位置平順接續，不退回袋子、不要求補揮。
- 尚未離手的已觸發投擲，恢復後只完成一次出手。
- 結局熊與登乘隊伍從原位置接續，不產生副本。
- 若在換場中，先完成剩餘移動與下車，再開始供禮。
- 清除暫停前未成立的揮擲速度紀錄與蹲下確認，重新取得連續動作資料。

回收落物時使用實體位移，不用淡出再出現交代。恢復過程先不釋放其他物件，確保小玩家看得懂禮物重新從雪橇來、炸蛋重新從小精靈手邊來。

追蹤中斷同樣凍結流程與援助；恢復時保留進度，重新建立姿勢資料。

**室內新造型：淺而寬的住宅剖面**

室內採**低矮、橫向展開的住宅剖面單體**，像把街屋外牆朝觀眾的一面拿掉，露出一段乾淨的生活空間。

TP014 固定包含：

- 大片奶油暖灰背牆。
- 兩側短牆切面。
- 灰米色薄地板帶，交代磨石子地的感覺。
- 一側連在結構裡的低床與床頭矮櫃。
- 另一側留白的收禮空間。

外形平直、邊角圓潤，不加裝飾邊框，不畫成黑洞窗戶，也不做盒子般厚重的四周框架。

床、矮櫃、牆與地板永遠一起移動，固定在同一張建築單體。熟睡住戶、樹、襪子、滑道與禮物分開，維持各自所需的動作與遮擋。矮櫃保留為固定家具，但不再放點心餐盤。

前兩段使用一戶較寬的房間，第三段起左右各一戶。兩戶共用同一張 TP014，其中一戶鏡像，讓睡眠角落在兩側、收禮區靠中間。每戶仍有獨立煙囪與滑道，中間留下房屋分界。

CH303 男孩與 CH304 女孩各自躺在房間自帶的床上，不另加 TP012，也不把人物放在地板或矮櫃頂。**每戶的收禮區都在床的對面那一側**，不因房間鏡像或住戶交換而改成床邊堆禮物。

兩戶使用相同的暖灰殼體，不新增不同牆色版本。主要辨識靠男孩短髮、女孩腦後髮束的剪影、不同被子色系與相反的家具排列。

**煙囪新造型：矮磚口接奶油灰滑道**

TP010 為**矮胖、寬口、少量大磚塊的紅磚煙囪頭**：

- 高度只需從屋頂突出到人物腰腹附近，不再像整座磚塔。
- 上方開口寬大，厚口沿圓潤。
- 朝觀眾的前側保留剖開缺口，能看見禮物進入。
- 底端開放，接到下方滑道。
- 不加帽蓋、煙霧、火焰、歐式壁爐或裝飾銅管。

TP013 為**短直、寬敞的開放煙道內襯**：

- 淺暖灰到奶油灰的霧面通道，兩側只有簡單厚邊。
- 暖灰褐內面保留足夠辨識，不畫成純黑洞。
- 上端直接接煙囪底部，穿過樓板處持續可見。
- 下端以柔和圓角收口，接到樹旁與襪口前的小空地。
- 沒有密集磚紋、格柵、橫檔或封住前方的牆。

兩件合起來仍是一條煙囪送禮通道，**不是兩座不相連的裝飾**。分件目的在於讓屋頂入口維持清楚的寬口，室內通道配合淺帶高度，不再被整座長塔的比例綁住。

不要求玩家自選煙囪結構。每戶固定同一組入口與滑道，整體跟著房屋換場。

**室內前後關係**

由後往前為：

住宅殼體與固定家具 → 聖誕樹、掛襪、滑道 → 熟睡住戶 → 正在送達與已停妥的禮物。

通道區另保持前方可見，牆與樓板不能蓋斷禮物路徑。床面上只放熟睡住戶，不讓禮物經過頭部或落到被子上。

襪口使用必要遮擋，讓車尾或紅包上緣露出；不需要滿襪版，也不把整件禮物貼在襪子外面。

**最下面是住宅基座**

畫面高度約 92～100% 以平淡的暖灰建築基座收住：

- 上沿接室內地板，清楚是房屋的一部分。
- 下方以稍深的霧藍灰或暖灰色面延伸到底。
- 只用簡單色塊，不新增基座圖片。
- 沒有馬路、路緣、輪胎、行道磚、車道線或盆栽。
- 不壓成黑底，不加濃重投影或發光邊緣。

觸控按鈕可放在基座帶與側邊空白，不遮住室內的襪口、住戶臉與禮物終點。

**固定低刺激畫風**

【畫風】平安夜深夜的台灣街屋與淺室內剖面，立體卡通 CG 渲染，像上了霧面漆的塑膠玩具公仔，圓潤簡化、無黑色描邊、柔和頂光；以磚紅、奶油白、淺土褐、霧藍與灰綠為主，粉彩、低飽和、低對比，少量淡黃作替換點綴；燈飾只有不發光的實心小圓點，不使用霓虹、金屬高反光、光暈、星芒、爆閃或雪景。

深夜感來自霧藍灰遠景、安靜城市與熟睡住戶，不靠純黑配亮燈。BG001 與中景沿用固定而輕的環境疊色，角色與禮物保留原本清楚配色。

單張主體不超過四至五個主要色系。飛行、落物與投擲靠物件位移交代，不加軌跡、速度線、彩紙或飛行粒子。

接炸蛋時的幾點柔色星星是明確限定的短回饋：只有兩種柔和顏色、數量稀疏、大量留白，像玩具貼紙，不發光、不帶光暈、不爆閃。炸蛋本體、人物素材與其他場景不附帶這些星星。

## 五、角色設定

**聖誕老人**

原創圓胖老爺爺，磚紅霧面衣帽、奶油白大鬍子、圓鼻子、大圓眼睛、深暖灰鞋與腰帶。

沿用七張有效姿勢，不重生：

- CH001：待機。
- CH002、CH003：走路兩格。
- CH005：蹲下。
- CH006：四腳朝天吐舌頭。
- CH007：投擲預備。
- CH008：投擲出手。

投擲、空手趕小精靈、逗動物與結局沿用同一組出手姿。接炸蛋的兩大圈旋轉與微彈使用既有人物圖的整體動態，不新增轉圈影格。

登乘雪橇使用蹲姿與前後排列，不新增坐姿或駕駛姿；自動登乘不要求小玩家再做一次蹲下。

雙手的素材姿勢可以有主要投擲手臂，玩家輸入仍不分左右手。

**飛行麋鹿與雪橇**

由一隻原創麋鹿拉一台雪橇，作為固定隊伍：

- 麋鹿保留淺土褐身體、奶油白口鼻、深暖褐大鹿角與蹄、深暖灰普通鼻子。
- 正側面朝右，四腿收起呈飛行姿，長口鼻與大鹿角剪影清楚。
- 表情像很認真送貨、又有點得意的老搭檔。
- 雪橇保留磚紅車身、奶油色彎滑板與開放低車緣。
- 一條粗短、清楚的連接牽帶交代「正在拉雪橇」，不畫細碎繩網或鈴鐺。
- 後側貨艙有固定開口，禮物可先露出，再連續落下。
- 座位留空，供聖誕老人與回禮熊另外進入。

隊伍不含聖誕老人、袋子、禮物或餐盤。麋鹿與雪橇不分開動、不各自表演，不新增獨立跑腿或拍翅影格。

整隊水平鏡像處理回程，沒有左右不對稱標誌、字樣或品牌裝飾。鼻子不發光，飛行不帶光尾。本版沒有餵麋鹿事件。

**搗亂小精靈**

使用已完成的 CH601、CH602：

- 原創小個子，體型明顯比聖誕老人小，大圓頭、短軀幹、短而圓潤的四肢，肚子微鼓。
- 暖膚色、飽滿臉頰、小圓鼻、大圓眼睛，短而圓鈍的尖耳，沒有鬍子。
- 灰綠短軟帽，帽尾向後彎垂；奶油白帽緣，不加絨球或鈴鐺。
- 灰綠短上衣、奶油白圓領與袖口、霧面磚紅短褲、深暖灰圓頭短靴。
- 雙手不戴手套，衣服沒有腰帶、標誌或花紋，不畫成縮小版聖誕老人。
- 表情得意、調皮而討喜，不兇惡、不瞪人、不露尖牙。
- 正側面朝右，反向時鏡像。

CH601 是靠近鏡頭的手臂向後上方舉起、準備托蛋的姿勢；CH602 是同一隻手往右前上方伸展、已經出手的姿勢。兩張人物圖都空手，OB001 炸蛋另外放在手邊，出手後保持同一物件連續飛行。

兩張姿勢的臉型、配色、帽形、服裝與頭身比例一致。跺腳走人以既有兩張姿勢與整體動態表現，不增加離場影格。

**炸蛋**

OB001 是獨立卡通道具，外形為**上窄下寬的深暖灰蛋形，加上短而柔軟的奶油灰捲毛引線**。

- 蛋形明顯，不畫成球、方盒、圓柱或包裝禮物。
- 表面圓潤霧面，不塗成沒有層次的純黑剪影，也不做金屬反光。
- 引線像頭頂小捲毛，末端圓鈍，不點燃、不冒煙、不發紅、不發光。
- 保留稀疏簡單的呆臉：圓眼與小嘴，神情放空又好笑。
- 不加骷髏、警告圖案、倒數、裂縫、機械零件或尖銳裝飾。
- 固定使用深暖灰與奶油灰兩個主要色系。

從小精靈手邊到飛行使用同一張圖。接到後觸發聖誕老人轉圈，沒接到就在屋頂洩氣；沒有爆炸影格，也不新增爆炸素材。

**屋頂貓**

沿用 CH101、CH102，灰綠偏暖灰、奶油白口鼻、三角耳與長尾。只在屋頂占袋口或旁觀，不跳上供禮雪橇，不進室內。

第五段主題改為小精靈後，貓仍保留在後段事件選項中；出現時不與小精靈、大熊、麻雀或晾衣被事件重疊。

**麻雀**

沿用 CH201、CH202，淺土褐與奶油白，圓胖、短嘴、簡化翅膀。

牠接近的是**已從貨艙離開的獨立禮物**，不與飛行隊伍綁成一張，也不讓禮物從麻雀身上憑空生出。第七段與小精靈分袋輪流出現。

**熟睡小男孩**

沿用 CH303，虛構黑短髮小男孩，霧藍衣著、奶油暖灰被子。側躺、閉眼、夢裡微笑，始終在 TP014 自帶的床上。

淺室內帶裡保留完整頭部與抱被輪廓，不新增睜眼、坐起或歡呼版。

**熟睡小女孩**

使用 CH304，另一位原創虛構小朋友，柔和橢圓臉、深暖褐長髮在腦後束成粗而圓潤的低馬尾，淺土褐睡衣、灰綠被子。側躺閉眼，夢裡微笑，以腦後外露髮束的剪影和被子色系區別黑短髮男孩。

髮束與頭部、被子輪廓分開，縮小後仍可辨認；人物本體與男孩保持相近份量，不因髮束外伸而縮得特別小。不新增睜眼、坐起或歡呼版。

女孩躺在鏡像 TP014 自帶的床面上。兩位住戶只作人物與被子的整體微動，固定床架不跟著動；收禮區位於各自床的對面那一側。CH403 阿嬤退出。

## 六、重玩性設計

八段介紹順序、十六袋與結局不變。重玩改變已學內容的組合，不靠速度提高難度。

| 可變項目 | 變化方式 | 固定限制 |
|---|---|---|
| 禮物順序 | 五種禮物的排列改變 | 一袋四件，空中供四件，投擲仍四次 |
| 供禮位置 | 近身與稍遠位置交替 | 約七成近身，且每件確實從貨艙口離開 |
| 飛行折返位置 | 配合當袋落點縮短或延長短程往返 | 不飛出畫外繞圈，不製造等待 |
