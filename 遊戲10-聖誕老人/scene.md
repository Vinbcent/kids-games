# 遊戲10-聖誕老人 場景設計

## 一、畫面分層

本案使用 **2D Canvas 橫向捲軸**，固定側視鏡頭。全程是平安夜深夜，八段街區、十六袋禮物；每袋接滿四件，再逐件投進同一戶煙囪。

新版構圖固定為：**上方麋鹿雪橇供禮 → 寬大的屋頂操作區 → 下方淺室內收禮帶 → 住宅基座。**

兩戶住戶改為 **CH303 黑短髮男孩、CH304 綁髮女孩**，始終閉眼躺睡。第三段起介紹女孩家，取代原阿嬤家；CH403 退出本版。

角色採正側面，原圖朝右，反方向使用水平鏡像。物件採正面略側的統一視角，室內不是俯視房間。

接取與送禮期間鏡頭穩定，每完成兩袋才換街區。飛行雪橇在畫面內自行移動，各背景層不持續捲動。

以下百分比是**遊戲畫面的配置參考**，水平由左至右、垂直由上至下計算；不是生圖畫布、裁切或基準線要求。相對大小以屋頂聖誕老人站姿高度為 1。

**構圖界線**

- 一般屋頂行走線約在高度 **67%**，平台厚度延伸至 **70%**。
- 室內從 **70%** 開始，到 **92%** 結束，約占畫面高度兩成。
- 煙囪頭 TP010 與滑道 TP013 在 **70% 的樓板下緣線**接合。
- 室內地板下方接住宅基座，畫面沒有馬路、人行道、機車、商店或前景盆栽。
- 原先屋頂左側的常駐停靠區取消，主要人物走位範圍擴大為水平約 **16～86%**。
- 上方航帶、主要落物區與屋頂投擲區保留大片安靜背景，不用裝飾填滿。

### 遠景

**素材與數量**

- BG001：一種滿版台灣城市與夜空橫幅，以相鄰副本覆蓋可見範圍。

霧藍灰天空搭配偏淡、偏冷的平頂公寓輪廓。少量水塔與鐵皮屋頂交代台灣城市，不增加密集窗光、星海、光束或雪。

飛行隊伍、禮物下降路徑與投擲弧線後方保持平淡。遠方水塔不與麋鹿鹿角、禮物蝴蝶結或目標箭頭相黏。

可見遠方建築的高度約為主角的 0.6～1.2 倍，細節與明暗差弱於中景。

**移動與接續**

操作期間靜止；換場時以主場移動量的 0.18 倍向左移動。

相鄰橫幅交替水平鏡像。左右兩端維持通用天空與低矮城市輪廓，不放醒目獨特建築。橫幅填滿画面，接續邊緣不淡出。

BG001 是本版唯一需要左右鏡像接續的滿版背景。沿用既有圖，不新增夜景或結局版本。

### 中景

**素材與數量**

- TP003：每段可見一至兩棟公寓單體，依主場留白減量。

公寓約為主角高度的 1.3～1.7 倍，部分被主場住宅遮住。水塔、支架、鐵皮加蓋與鐵窗都固定在建築上，不獨立晃動。

換場倍率為 0.5，操作期間靜止。

中景只從主場兩側、屋頂後方或房屋間隙露出。TP014 的室內背牆不透明，中景不能透到床後、襪子後方或滑道裡。

**配置限制**

- 公寓最高輪廓不伸進一般飛行航帶。
- 主要落物區後方以平淡牆面或天空為主，不放高水塔。
- 水塔不放在煙囪入口正後方。
- 不使用 TP004 騎樓商店補滿下緣。
- 中景是後方另一排街屋，不充當主場住宅的牆面，避免換場時家具與房子分離。

### 主場

**屋頂操作區**

聖誕老人站姿高度約為畫面高度的四分之一，腳底約在 67%，一般帽尖約在 42% 附近。投擲伸手、翻滾與袋口全部保持完整可見。

TP001 使用二至三段相鄰平台，形成連續、安全的屋頂。兩端以平淡接面與少量重疊銜接，不露坑洞，也不要求跳躍。

主要人物中心可在水平約 16～86% 走位。實際可達落點須同時容納人物、袋子與完整禮物，不能只看人物中心是否還在畫面內。

第六段的淺階差只在屋頂表面形成小幅變化。人物與袋子沿連續路線自動銜接，室內上界、煙囪接縫與住宅基座保持穩定。

**袋子與接取區**

TP009 高約為主角的 0.5 倍，位於人物腳邊偏右。袋底接屋頂，袋口約在高度 54～57%。

人物左右轉向時只鏡像角色，不讓袋子瞬間跨到身體另一側。

一般禮物高約為主角的 0.22～0.3 倍，大熊約為 0.42 倍。從貨艙離開後，禮物有足夠的下降距離讓小玩家看清外形，再接近袋口。

落點約七成安排在袋口或一小步可達的位置，三成稍遠。接近操作邊界時，下一件引回內側，不連續引導追向畫外。

袋內禮物使用獨立 IT 素材。接到一件時袋子整體鼓一下，不新增空袋、半滿或滿袋影格。

**飛行雪橇的航線與速度**

VH001 是一隻麋鹿拉著空雪橇的固定合圖。麋鹿、短牽帶與雪橇一起位移、鏡像、升降和懸停；禮物與乘客保持獨立。

一般飛行隊伍含鹿角、收起的腿與滑板，**完整輪廓放在高度 9～25%**。貨艙釋放口約落在 22～25%，不進入上緣 0～8% 的 HUD。

全隊高度約為主角的 0.55～0.65 倍；依整張原圖長寬比保留完整橫向輪廓，不把隊伍拉扁。待送禮物可從開放貨艙露出，但不伸入 HUD。

| 航線項目 | 畫面安排 |
|---|---|
| 首次進場 | 從畫面左側進入，朝右飛；整隊與貨艙口完整可見後，才釋放第一件 |
| 一袋路線 | 短程去回各一段；向右送兩件，轉向後向左送兩件 |
| 一趟件數 | 四件，對應一袋；漏接物補回不算額外供禮 |
| 一般水平速度 | 以每秒約畫面寬度 8～12% 作構圖節奏參考；接近釋放位置與折返點時放慢 |
| 釋放節奏 | 約每兩秒一件，可依可讀性放慢；不是限時要求 |
| 折返位置 | 隨本袋落點調整，在畫面內完成，不要求每次橫跨整個螢幕 |
| 轉向方式 | 第二件已離開貨艙後，減速、水平鏡像，再向左；不翻筋斗，不展示背面 |
| 滿袋之後 | 停止供禮，移往側上方懸停，把注意力交給人物與煙囪 |
| 下一袋 | 利用前袋投擲及送達時間就位，接取開始即可接續供禮 |

速度是視覺節奏參考，**落點可達性優先於固定巡航速度**。路線太長時縮短路程，不用加速禮物下墜補時間。

主要供禮期間，全隊保持可見。隊伍接近畫面邊緣時，以鹿角與車尾都不被切到為界，不以雪橇中心仍在畫面內為界。

第一件下降時，隊伍前往第二個釋放位置；第二件下降時完成折返；第三件下降時準備第四件。雪橇的移動與接取重疊，不增加獨立等待。

**貨艙口與落物的座標關係**

每件禮物的來源固定為 VH001 上**後側貨艙後下緣的出貨缺口**。

貨艙出口中心是跟著圖片移動的固定位置，不是畫面上預先寫死的一個點。隊伍往右時，出口在雪橇左後方；整隊鏡像往左後，出口改到右後方。

每件禮物依下列順序出現：

1. 先選定小玩家可達的袋口位置。
2. 隊伍移到能從貨艙自然送往該位置的位置。
3. 同一件禮物先露在貨艙口，隨隊伍一起移動。
4. 釋放時，禮物的接續位置就是**當下貨艙出口的位置**。
5. 離口後以接近垂直的方向下降，只有少量平緩的水平延續。
6. 入袋、卡袋或漏接補回都接續原物件。

在釋放交界，禮物前後兩個狀態的位置相同：**貨艙內最後位置＝自由下降起點**。不能先藏起艙內禮物，再在較低處生成另一件。

水平鏡像時，出口相對隊伍中心的左右偏移一併翻轉，高度關係不變。尚未釋放的禮物跟著出口；已離開的禮物保留自己的下降位置與方向，不能跟隊伍一起翻到另一側。

轉向期間不釋放新物件。下一件在转向完成後於新的貨艙口露出，避免待送物在畫面中突然橫跳。

已釋放的禮物不因小玩家突然走開而瞬間追人。偏差由寬鬆接取、放緩下降及屋頂彈回處理。

一袋四件包含已釋放、尚未入袋的物件。四件都已安排後，貨艙不再送出第五件。

**送禮期間的懸停位置**

一般懸停仍位於高度 9～25%，優先使用水平約 4～32% 或 68～96% 的側上方空間，依隊伍實際寬度向內調整。

- 左戶收禮時，優先停在右上側。
- 右戶收禮時，優先停在左上側。
- 單戶時使用較空的一側。
- 投擲弧線主要放在高度約 30～60%，最高處與隊伍最下緣保持清楚間隔。
- 不把隊伍停在箭頭後方，也不讓牽帶或滑板壓住禮物弧線。
- 懸停只作極小幅度的整隊起伏，不反覆彈跳。

送禮期間貨艙沒有下一袋禮物先掉下來。最後一件正在送達時，隊伍可以先移往下袋起點或接人位置。

**TP014 住宅剖面與固定家具**

TP014 是一張低矮、橫向展開的建築單體，包含：

- 奶油暖灰背牆。
- 兩端短側牆切面。
- 灰米色薄地板。
- 一側的低床、床墊與連體床頭矮櫃。
- 另一側空白的收禮區。

床、矮櫃、牆和地板永遠一起移動，不另疊 TP012。住戶、餐盤、樹、襪子、滑道與禮物分開。

原方向的床在左側，床頭及矮櫃靠室內中央。左戶的 CH303 頭在右、腳在左；右戶鏡像殼體後，CH304 也鏡像，頭在左、腳在右。兩個孩子的頭都靠各自矮櫃，身體確實躺在床面上。

住宅整體放入 70～92% 的淺帶，地板約在 90～92%。不把舊深房間整體壓扁，也不拉扁人物；使用新殼體的低矮構圖，再安排独立物件。

兩戶共用同一張殼體。女孩家的淡霧藍灰只作為背牆的固定、輕微色調區別，不另做一張房間圖，也不連住戶、樹與禮物一起染色。

收禮區另有以下固定規則：

- 男孩家已送達物件不向水平約 28% 左側延伸；女孩家不向約 72% 右側延伸。
- 這條分界包含玩具車尾、熊耳朵、紙袋上緣與襪子外露物，不只限制物件中心。
- 襪口位於滑道出口旁、偏向樹的一側，與床頭分開。
- 樹旁禮物分為淺淺的前後兩排，每排最多四件，最多保留本段八件。
- 前後可以少量重疊，但每件至少保留主要辨識輪廓；不把後排全部遮成看不見。
- 襪內小禮物使用略微錯開的外露輪廓，不另排到地板或床上。
- 新禮物送達時，只有它做一次小反應，已到位物件不一起跳動。
- 房間隨換場整戶退出，成果才一起離開；不在第二袋開始時清空第一袋。

### HUD

HUD 固定於畫面，使用簡單向量圖示或既有素材縮圖，不新增圖片。

首次介紹新事件時，其他主要事件暫停。一袋最多一項卡熊、動物、被子或點心。

**每兩袋的換場畫面**

1. 第二袋最後一件正在送達時，VH001 已移往屋頂一側上方。
2. 四件全部落定、必要點心結束後，隊伍降低到平台外側。
3. 隊伍低空停穩，滑板與屋頂仍有清楚空隙，座位靠近可安全銜接的一側。
4. 聖誕老人與空袋短距離移到雪橇旁。人物切 CH005，自動進入低車緣座位。
5. 隊伍、人物與袋子一起向右低空飛行，鏡頭開始推進街區。
6. 舊住宅連同住戶、餐盤及已送達禮物一起向左退出。
7. 新住宅、屋頂、煙囪與滑道一起進場。隊伍在新屋頂外側懸停，人物與袋子自動移到內側安全區。
8. 隊伍升回航帶，第一件露在貨艙口，接續下一袋。

低空接人只在供禮與投擲都結束後使用。此時隊伍可離開一般 9～25% 航帶，降低至座位接近人物的高度；不是一般遊戲期間的巡航路線。

### 援助與追蹤中斷

約五秒沒有任務推進時，援助使用當前物件接續：

- 雪橇縮短路程，讓下一件從目前袋口附近上方的貨艙離開。
- 漏接物放緩、彈回，不另補一件。
- 熊自行輕壓，貓側倒，麻雀鬆口，被子整組抬高。
- 投擲逐件示範，只補送尚未出手的物件。
- 點心、登乘與結局接續原演出。

反覆翻滾、空揮或亂晃不永久重設等待。連續無操作時跨階段延續援助，不在每一件之前重新等五秒。

追蹤中斷時，隊伍、待送物、下降、投擲、送達、點心、換場及援助一起凍結。恢復後重新取得動作資料，不在看不到玩家時偷偷完成進度。

### 護眼暫停與恢復

護眼覆蓋層出現時，全畫面事件凍結五秒，包含隊伍位置、貨艙待送物與所有跨樓板的送達演出。

解除採用**推回起點**，並保留已取得進度：

- 未接到的落物回到供禮來源。隊伍與同一件禮物先以短而可見的回收動作重新對上貨艙口，再慢慢釋放。
- 不把起點改成任意畫面上緣，不淡出再生成。
- 若貨艙已有下一件待送，先保留它，依原順序處理回收中的物件。
- 干擾中的貓、麻雀回事件起始位置，重新預告；麻雀叼住的仍是原禮物。
- 已入袋、已出手與已送達物件保留。
- 已出手禮物從原弧線或滑道位置接續，不退回袋子。
- 尚未離手的已觸發投擲恢復後只完成一次。
- 餐盤、回禮熊及乘客保留原位置，不產生副本。
- 換場中先完成剩餘飛行、懸停與下車，再恢復供禮。
- 暫停前未成立的揮擲速度紀錄與蹲姿確認清除，重新建立動作資料。

回收期間不再釋放其他物件。已進入煙道的禮物不構成威脅，保持原路可見即可。

### 大結局與再次遊玩

第八段最後住家從抵達時，就在矮櫃旁放好 IT003 回禮熊。它與樹旁送達成果分開，住戶沒有拿著它。

第十六袋四件全部落定後：

1. 隊伍停止供禮，在上方等候。
2. 聖誕老人沿最後住家的煙囪與滑道下去，發現櫃旁回禮。
3. 人物與熊沿可見原路回屋頂，室內原位置不留熊的副本。
4. 熊在屋頂恢復較大的互動份量。
5. 蹲下時 CH005 接 CH006，熊輕坐圆肚子，人物四腳朝天吐舌頭。
6. 揮擲時 CH007、CH008 接整體短彈起，人物與熊一起落回屋頂；沒有先蹲也能演。
7. 笑話期間隊伍已降低到屋頂外側。熊與人物先落穩，再依序移入雪橇。
8. 隊伍載著聖誕老人、袋子與熊缓緩升高，向右出發。

互動笑話約八秒，無操作約五秒後由援助接續。不要求把熊準確投進雪橇，也不需要孩子做跳躍動作。

貓與麻雀留在原屋頂。男孩與女孩始終閉眼躺睡，不歡呼、不合照、不揮手。

完成畫面把載人隊伍留在上方完整可見的位置，小幅懸停；下方住宅與基座保持安靜，只有一顆「再送一次」圖示。

體感重玩須等待前一動作回落，再接受新的一次揮擲。重玩回到單戶男孩家與同一深夜色調。

## 三、色彩與光線

**可直接沿用的畫風句**

【畫風】平安夜深夜的台灣街屋與淺室內剖面，立體卡通 CG 渲染，像上了霧面漆的塑膠玩具公仔，圓潤簡化、無黑色描邊、柔和頂光；以磚紅、奶油白、淺土褐、霧藍與灰綠為主，粉彩、低飽和、低對比，少量淡黃作替換點綴；燈飾只有不發光的實心小圓點，不使用霓虹、金屬高反光、光暈、星芒、爆閃或雪景。

**深夜與下緣收色**

深夜感由霧藍灰城市、安靜屋頂與熟睡住戶建立，不依靠黑底與亮燈反差。

| 區域 | 色彩安排 | 辨識要求 |
|---|---|---|
| BG001 遠景 | 固定、輕薄的霧藍灰環境色 | 天空與平頂城市分得開，不壓成純黑 |
| TP003 中景 | 比遠景稍清楚，保持淡灰與冷灰 | 水塔與鐵皮輪廓清楚，窗面不發光 |
| 飛行隊伍 | 保留磚紅、奶油白與土褐原色 | 鹿角、空座位、貨艙口能分辨 |
| 屋頂平台 | 淺暖灰與稍深暖灰前緣 | 與鞋底、袋底及煙囪分開 |
| TP010、TP013 | 磚紅入口、奶油灰厚邊、暖灰褐內面 | 接縫色調連續，通道不是黑洞 |
| 男孩家 | 奶油暖灰背牆，霧藍袖口與奶油暖灰被子 | 黑短髮圓頭完整可見 |
| 女孩家 | 背牆略偏淡霧藍灰，土褐袖口與灰綠被子 | 腦後髮束與牆面保持明度差 |

下緣基座使用少量大片實色色面。上沿比下方略亮，交代樓板與建築重量；不畫強烈漸層、濃重投影或高反光。

兩戶背牆的色差輕微而固定，不取代剪影辨識，也不需要兩張殼體。住戶被子維持各自原色，避免將女孩灰綠被子染成牆色。

環境疊色限定於背景及指定背牆，不用整片深色遮罩壓住角色、禮物與貨艙。

**低刺激與清楚輪廓**

- 遠景最淡，中景次之，主場依留白與簡化形狀突出。
- 主要禮物路徑後方避開窗格、鹿角與晾衣架。
- 袋口、煙囪入口與襪口都用溫和明度差表現，不畫純黑洞。
- 樹與灰綠被子放在不同區域，不能連成同一團。
- 已送達禮物安靜停妥，不一起跳動或閃爍。
- 飛行與投擲只靠物件位移，不加軌跡、速度線或粒子。
- 燈串只是稀疏實心圓點，全程不點亮。
- 單張主體不超過四至五個主要色系。

**設定圖與一致性**

- 貓、麻雀與 CH303 延續既有角色設定。
