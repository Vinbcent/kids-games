## 一、現況（Canvas 幾何體版「水泥車大作戰」）

**一句話**：小朋友開著水泥車在**高架橋**上左右跑，雙手高舉就從攪拌鼓的滑槽倒下水泥，往橋下的馬路澆——澆進 🛻 空貨車的斗裡就「叮！滿載出發」計數 +1；澆到路過的小汽車就把它整台黏住，輪子空轉、狂按喇叭、抖三秒後咻地掙脫跑掉（純搞笑不扣分）。沒有 Game Over。

### 體感對應（**完全保留，不要動**）

| 身體動作 | 遊戲操作 | 可靠度 |
|---|---|---|
| 整個人左右站位 | 高架橋上的水泥車左右開 | ★★★ |
| 雙手高舉（兩手腕都高過鼻子） | 倒水泥（無限量、按住就一直倒） | ★★ |
| 手指模式：按住畫面 | 邊拖曳移動邊倒水泥 | ★★★ |

### 現在的畫面（要換掉的東西）

- 天空：一道 linear-gradient 藍；太陽與雲是 🌞 ☁️ emoji；地平線小鎮是一排 🏠🏢🌳🏫🏪 emoji。
- 馬路：兩個 `fillRect` 深灰色塊＋一條白色虛線分隔。
- 高架橋：三個灰色 `fillRect`（橋面／橋緣／兩根橋墩）＋一排 `stroke` 直線當欄杆。
- 水泥車：三顆黑圓當輪子、圓角矩形駕駛艙、一個橢圓當攪拌鼓（裡面三條會轉的色條）、一條粗線當滑槽。整台車會隨等級換 7 種螢光色。
- 街上六種車（貨車／小汽車／跑車／計程車／警車／公車）：全部是圓角矩形＋亮藍色車窗＋黃色圓點車燈拼出來的，顏色是隨機挑的高飽和色。
- 水泥：一顆顆灰色圓形當水泥滴、扁橢圓當地上的水泥灘、車頂一坨半橢圓當黏住的水泥。
- 特效：emoji 粒子（⭐🎉✨💦😵）＋ 黏住時頭上冒 ❗🎵🚨。

### 玩法細節（重製版要一比一保留，數值以 index.html 為準）

1. **兩條車道**：遠車道（畫面 y≈0.775、車子縮 0.78 倍、往左開）、近車道（y≈0.915、原尺寸、往右開）。車輛從畫面外進場，開出去就消失。同時最多 6 台，最快每 0.9 秒生一台，入口 0.26 範圍內有車就不生。
2. **生成機率**：貨車 40%、小汽車 20%、計程車 12%、警車 10%、公車 10%、跑車 8%。跑車最快（0.13~0.18／秒）最難澆到，公車最慢最大。
3. **倒水泥**：雙手高舉 → `pourLevel` 平滑上升 → 從滑槽口噴出一顆顆水泥滴（重力下落）→ 打到車就累積。有一條白色瞄準虛線從滑槽垂到地面。
4. **貨車倒滿**：斗裡的水泥從底往上長，滿了 → 「叮！」音效、⭐🎉✨ 噴發、車速 ×3 開心開走、計數 +1、畫面震一下。每 5 台放煙火＋英文稱讚語音，每 10 台水泥車換一個新顏色（等級）。
5. **小汽車被黏住**：黏 3 秒——整台車抖動、輪子空轉、依車種發出不同叫聲（小汽車叭叭、計程車叭～叭～、警車咿─嗚─紅藍燈狂閃、公車低音氣笛噗──、跑車嗶嗶嗶）、頭上冒 ❗🎵、車頂一坨水泥。3 秒後「咻！」上滑音掙脫加速跑掉。**一台車只會被黏一次**（`escaped` 旗標）。不扣分、沒有懲罰。
6. **沒有失敗、沒有倒數、沒有 Game Over。**
7. 護眼機制（太靠近電視 → 警報音＋強制暫停 5 秒倒數）全系列共用，不用你設計。

## 二、這次重製要你做什麼

### 引擎與構圖（Claude 已定，照這個設計）

**維持 2D Canvas，把所有幾何體換成 `drawImage` 貼圖**（和遊戲3、4、5、6 一樣）。畫面是**側視的台灣街景，上下分層**：

```
   ┌──────────────────────────────────────────┐
   │  ① 天空／遠景街屋（橫幅背景）                 │  ← BG001
   ├──────────────────────────────────────────┤
   │  ② 高架橋（y≈0.30）：水泥車站在這裡左右開      │  ← 玩家
   │     ↓ 水泥從滑槽落下                        │
   │  ③ 橋下空間（天空色）                        │
   ├──────────────────────────────────────────┤
   │  ④ 遠車道 y≈0.775（往左開，車小 0.78 倍）     │  ← 目標
   │  ⑤ 近車道 y≈0.915（往右開，車大）            │  ← 目標
   └──────────────────────────────────────────┘
```

這個版面已經符合爸爸的偏好：**操作者在上、目標在下、有縱深、多元素**。不要把它改成同一條路。

### 請你回答／交付的三件事

1. **形象**：台灣預拌混凝土車（水泥車）與台灣街車（小發財車／小黃／警車／公車／轎車／跑車）的**結構剪影特徵**，四歲小孩要能分辨。哪些細節在電視上縮到很小還看得出來、哪些是白畫的。
2. **數值手感**：讀過 `index.html` 的實際數值後，指出哪些速度／間距／時間讓「追著車澆水泥」這件事好玩或難受。特別是：跑車 0.13~0.18 是不是太快到根本澆不到？貨車倒滿需要的水泥量與貨車過場時間搭不搭？
3. **回饋效果**：貨車倒滿、小汽車被黏住、掙脫跑掉這三個瞬間，用什麼「素材」表現最有效（不是用粒子噴 N 份，而是像遊戲5 那樣**一張貼紙放大淡出**、或**平常表情／反應表情兩張圖對比**）。

### 已知的坑（前幾款踩過，不要重蹈）

- FX 素材本身就是「一整組貼紙」，不要丟進粒子系統噴 N 份。
- 街景車要用**高度**正規化，不要用寬度（直幅的車會爆高）。
- 同一台車的不同表情用固定寬度畫（bbox 寬＝車長，天然一致）。
- 顏色安靜：爸爸明講過「畫面過於華麗，視覺刺激太強」。
