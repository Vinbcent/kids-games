# 給 Codex（GPT）的專案指令 —— 遊戲3 挖土機挖挖樂

【畫風】立體卡通 CG 渲染，像上了亮漆的塑膠玩具公仔，圓潤沒有稜角，無黑色描邊，色彩飽和明亮，柔和頂光。題材是工地與地底探險：黃色工程機具、橘色警示、咖啡色土層、地底藏著閃亮寶物與化石。所有機具與車子都擬人化，有又圓又大的眼睛和笑臉，像玩具車；表情誇張討喜。

【工作模式】
- 訊息說「做企劃」「做場景設計」「做素材清單」：交出文件，不要生圖。文件格式照 04。要求寫檔時就直接寫到指定路徑，不要只印在對話裡。
- 訊息以 `$imagegen` 開頭：那是生圖，一則一張，直接生成，不要先問問題、不要加文字說明。

【每一張圖的鐵則】
1. 畫面只有一個主體。不要地面、不要台座、不要投影陰影、不要第二個角色、不要背景場景物件（我明說「橫幅背景」的那張除外）。
2. 圖上不可以有任何文字、數字、字母、簽名、浮水印、邊框、分格線。
3. 主體完整入鏡，四邊都要留白，任何一處都不可以被畫布邊緣切到。
4. 背景：**一律填滿鮮豔的洋紅色純色底，整個畫布同一個洋紅色。** 絕對不要黑色背景、不要透明、不要棋盤格、不要漸層、不要任何光暈或發光效果。（主體本身不要用粉紅／洋紅／紫紅色。）
5. 不要光線特效、不要動態模糊、不要粒子或飄浮碎屑。
6. 同一個角色或場景的不同張，配色、比例、造型、配件必須完全一致；附了設定圖就嚴格照設定圖，不要自己改設計。
7. 只畫要求的那一個姿勢或畫面。不要畫成多格設定表、不要一張圖裡放好幾個版本。
8. 表情要好笑、誇張、討喜，不可以可憐、兇惡或恐怖。
9. 不要模仿任何現有卡通、遊戲、動畫或品牌的角色造型。
10. 細節不要過碎：這些圖會在電視上以很小的尺寸出現，靠高對比剪影與簡化造型。
