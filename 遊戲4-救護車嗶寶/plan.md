# 遊戲4-救護車嗶寶 企劃
## 一、一句話說明

小玩家化身原創救護車「嗶寶」，用身體左右換車道，在卡通城市中收集糖果、閃過障礙、救援受傷的小車車，集滿能量後高舉雙手變身機器人，展開無敵救援衝刺。

## 二、玩法核心
### 操作動作

嗶寶會自動向前行駛，整款遊戲只使用兩種已驗證的體感訊號，不增加跳躍、蹲下、揮手或精細手勢。

| 小玩家的身體動作 | 遊戲操作 | 手指模式 | 即時回饋 |
|---|---|---|---|
| 身體向左、回到中央或向右移動 | 嗶寶在三條車道間平滑換道 | 在畫面上左右拖曳 | 嗶寶車身朝換道方向微傾，輪胎彈一下，車道提示短暫亮起 |
| 變身能量集滿後，雙手同時高舉過頭 | 啟動機器人變身與無敵衝刺 | 點擊畫面上方的發亮能量條 | 能量條跳動、警示燈閃爍，嗶寶先正面帥氣登場，再切換成背面機器人衝刺 |

能量未滿時高舉雙手不觸發任何操作，也不播放責備聲音。能量集滿後會持續保留，讓小玩家自行決定何時變身。

### 一局的流程

1. **準備與倒數**  
   嗶寶停在中央車道晃動待命，畫面以左右箭頭動畫示範換道，再播放「三、二、一，救援出發」倒數。

2. **暖身路段**  
   開始的數排只出現單顆糖果與簡單的左右收集路線，不放雙重障礙。小玩家先成功完成幾次換道，再遇到第一台受傷小車。

3. **核心跑酷循環**  
   道路持續產生下列事件排：

   - 收集排：糖果、愛心糖、星星糖或杯子蛋糕出現在一至兩條車道。
   - 引導路線：同一種道具沿相鄰車道排成短弧線，鼓勵小玩家連續左右移動。
   - 障礙排：三角錐、石頭或施工護欄擋住一至兩條車道，永遠保留至少一條安全路線。
   - 救援排：受傷小車單獨出現，附近不安排會干擾判讀的障礙。
   - 磁鐵排：磁鐵單獨出現；取得後約六秒內，附近的一般收集物會彎曲飛向嗶寶。

4. **收集與累積能量**  
   能量條採十格圖像化顯示：

   - 一般糖果、星星糖或杯子蛋糕：加十分與一格能量。
   - 愛心糖：加二十分與兩格能量。
   - 磁鐵：加一格能量並啟動吸取效果。
   - 救援成功：加五十分與三格能量。
   - 機器人撞飛障礙：每個加五分。

   分數只用來記錄成就，不會被扣除；能量也不因碰撞而減少。

5. **救援小車**  
   受傷小車會在後窗露出「痛痛但可愛」的表情，車身輕輕搖晃；求救圖示由程式在上方閃動。嗶寶進入同一車道並碰到小車後，畫面短暫放慢，播放治療鈴聲，小車切換成治好笑臉、開心彈跳，再加速駛向路邊醫院。十字愛心與煙火會立即爆開，讓救援成為全局最醒目的獎勵。

6. **機器人變身**  
   十格能量全滿後，能量條持續發亮並提示雙手高舉。成功觸發時，嗶寶正面機器人形態快速登場，再切回追尾視角衝刺約六秒。期間速度提高、保持無敵，所有障礙都會被撞飛旋轉，普通收集物自動靠近。結束時嗶寶翻身變回救護車，遊戲不中斷。

7. **救援里程碑**  
   每成功救援五台小車，就進行一次短暫的「超級救援慶典」：最近救好的小車在路邊跳動揮手，煙火升起，救援計數放大，隨後立即回到跑酷。慶典不是關卡終點，遊戲可持續進行。

### 勝負與結束條件

- 本作沒有 Game Over、生命值、倒數壓力或總失敗。
- 每次取得道具、完成救援、集滿能量、成功變身及救援五台小車，都是一個清楚的局部成功。
- 撞到障礙只會觸發好笑的翻滾表演，不扣分、不扣能量；嗶寶會自行站穩並繼續前進。
- 錯過受傷小車不會出現責備、哭泣或扣分。小車會慢慢駛離，下一次救援機會會較快出現。
- 遊戲採無盡里程制，沒有強制終點。只有小玩家或陪同大人主動離開、重新開始時才結束本局。
- 骨架追蹤暫時遺失或觸發護眼提醒時只會暫停，不視為結束或失敗。

## 三、難度與挫折控制

- **先成功再變難**：暖身路段先讓小玩家取得數次道具並完成第一次救援，再開始出現雙重障礙與較長的換道路線。
- **速度緩慢增加並設上限**：里程增加時只逐步提高行駛速度與事件密度；到達適合體感反應的上限後不再加速。
- **永遠保留安全車道**：普通障礙排最多封住兩條車道，不出現三線全封，也不要求瞬間跨越兩條車道。
- **救援事件保持乾淨**：受傷小車出現時，同一距離不放障礙或磁鐵；前方用柔和光圈提示目標車道。
- **判定刻意寬鬆**：道具與救援的取得範圍比圖像略寬；換道途中接近目標車道即視為成功。障礙碰撞則較保守，模糊邊緣不算撞到。
- **碰撞是玩具，不是處罰**：碰撞後嗶寶使用暈頭笑臉整台翻滾，星星繞圈，再以彈簧般的動作站穩；接著約兩秒無敵，避免連續碰撞。
- **連續碰撞會暗中降速**：短時間內多次撞到障礙時，道路速度暫時降低、下一排優先產生糖果，讓小玩家自然回到成功節奏。
- **錯過救援不製造罪惡感**：不播放悲傷旁白、不顯示叉號；受傷小車只會揮揮手離開，系統很快安排新的救援機會。
- **能量滿了不催促**：變身機會會一直保留，只在能量剛滿與稍後各提示一次，不連續重複語音。
- **避免畫面過載**：同一瞬間只呈現一個主要決策；救援、磁鐵與複雜障礙不疊在同一排。
- **視覺辨識明確**：可收集物採圓形、心形與糖果形等柔軟輪廓；障礙採尖角、硬塊與橫桿輪廓。兩類不使用相近的形狀與主色。
- **動作安全**：只要求站立左右移動與雙手高舉，不要求跳躍、快速蹲起、轉身或衝向鏡頭。
- **護眼暫停**：小玩家過度靠近畫面時，全螢幕覆蓋層立即暫停遊戲並引導退後；確認距離安全後才恢復。

## 四、畫面分層

| 層級 | 畫面內容 | 動態與用途 |
|---|---|---|
| 遠景 | 藍天、白雲、柔和遠山與糖果色城市天際線 | 遠景橫幅極慢左右平移；獨立雲朵以不同速度飄動，建立開闊城市感 |
| 中景 | 醫院、兩種糖果色房子、圓冠樹與路燈 | 沿道路兩側從消失點向鏡頭移動並逐漸放大；左右交錯排列，避免形成單一水平線 |
| 主場 | 往遠方收斂的三線道、車道標線、道具、障礙與受傷小車 | 馬路由程式繪製；跑道物件依距離縮放並由遠而近移動。道具與障礙正面朝鏡頭，受傷小車以背面朝鏡頭 |
| 玩家層 | 嗶寶救護車或機器人形態，固定在畫面下方偏中央 | 嗶寶以背面追尾視角呈現，只在三條車道間左右移動；換道時車身微傾，碰撞時整張圖旋轉 |
| 前景特效 | 撞擊星星、治療十字愛心、煙火與機器人速度線 | 只在對應事件短暫出現，保持大形狀、高對比，不遮住下一排道路資訊 |
| HUD | 距離、分數、救援台數、十格變身能量條、磁鐵剩餘狀態 | 以大圖示為主、中文短字為輔；能量滿時整條跳動發亮，救援里程碑時救援數字短暫放大 |
| 暫停覆蓋層 | 準備倒數、追蹤暫停、護眼提醒與退後倒數 | 覆蓋全螢幕並凍結道路，不讓遊戲事件在小玩家看不到時繼續前進 |

鏡頭固定在嗶寶正後方略高處微俯視，馬路向中央遠方消失點收斂。主角與受傷小車呈現背面；障礙與道具面對鏡頭；路邊景物使用正面或正側面。所有元素都以遠小近大的方式維持一致透視。

## 五、角色設定

- **嗶寶／救護車形態**  
  造型以 `REF001` 為基準。嗶寶是原創的白色圓潤玩具救護車，車身搭配紅色與亮藍色條紋、紅十字圖形與車頂警示燈，不出現任何文字或字母。為了讓追尾視角仍看得到情緒，後窗設計成圓潤的大眼睛與笑臉；尾燈、保險桿與輪胎也會配合表情彈動。個性熱心、樂觀、稍微冒失，撞倒後不害怕，反而會暈頭晃腦地笑著爬起來。

- **嗶寶／機器人形態**  
  保留救護車的白、紅、亮藍配色與紅十字；警示燈位於頭頂，車頭結構變成胸口，車輪收在手臂與小腿外側。身形像圓潤的塑膠玩具機器人，不使用尖銳武器或戰鬥裝甲。背面衝刺要能清楚辨認仍是嗶寶變成的角色；正面登場則露出自信的大眼睛與得意笑臉。

- **受傷小車車家族**  
  造型以 `REF002` 為基準，共有三種高辨識度車型：橘色圓頂小轎車、亮藍色短胖廂型車、檸檬黃色迷你旅行車。三台都以背面朝鏡頭，後窗具有擬人化眼睛與嘴巴。受傷版使用歪斜眼神、鼓起臉頰、車身小幅搖晃與一處醒目的繃帶或 OK 繃，呈現「痛痛但可愛」；不流血、不破裂、不冒黑煙，也不做悲慘表情。治好版改成彎彎笑眼、張嘴大笑與活潑彈跳。

- **城市世界的角色感**  
  房屋、醫院、樹與路燈維持圓潤玩具造型，但不增加臉孔，避免與需要救援的小車搶焦點。醫院使用清楚的紅十字辨識，不放醫院名稱、字母或招牌文字。

- **旁白語氣**  
  旁白像活力十足的救援隊夥伴，句子短、情緒明確，先說動作或成果，再給鼓勵。碰撞旁白要跟著笑，不責備；救援旁白則明確說出小車已經安全、舒服多了，強化「我真的幫到牠」的成就感。

## 六、重玩性設計

- 每局隨機重排收集排、引導路線、障礙排、磁鐵排與救援排，但始終遵守安全車道與救援不受干擾的規則。
- 三種受傷小車會輪流出現，避免長時間只看到同一台；治好後的跳動、甩尾或開心晃動可由程式隨機選擇。
- 糖果、愛心糖、星星糖與杯子蛋糕輪替出現，收集路線可形成直線、左右短弧或安全車道提示。
- 路邊兩種房屋、醫院、樹與路燈每局改變排列順序與左右側，遠景橫幅則緩慢平移，讓城市不會像固定佈景。
- 救援成功時從多句英文稱讚中隨機播放；每五次救援改用專屬里程碑旁白，降低重複感。
- 能量滿後不自動變身，小玩家可選擇立刻舉手，或先保留到障礙較多時再啟動，形成簡單但有意義的自主決定。
- 機器人模式中的障礙飛出方向、旋轉速度與煙火位置可隨機變化，同一張素材也能產生不同喜劇效果。
- 碰撞翻滾可隨機採用一圈、兩圈或左右搖晃收尾，但總時間保持短促，不阻礙遊戲進度。
- HUD保留本局距離、分數、救援台數與最佳救援紀錄，供陪同大人看懂成果；遊戲不要求小玩家打破紀錄才能獲得慶祝。
- 每五台救援一次小慶典，每十台再增加更大的煙火與路邊小車歡呼，讓無盡模式持續提供可預期的新目標。
