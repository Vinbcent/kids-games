# 🚛 垃圾車來囉（遊戲 5）

## ✨ 2026-08-26 新美術版（index-新美術.html）

**玩法一比一保留，只換美術。** 原本是 Three.js 用圓角方塊＋emoji 拼出來的 3D 街道，重製成 **2D Canvas 分層街景 ＋ 39 張 AI 素材**：

- **四層縱深街景**：天空／遠山／台灣透天厝街屋（背景，視差最慢）→ 街景車道（遠，車畫小）→ 收集車道（中）→ 紅磚人行道（近，小主人站這）
- **兩台車照台灣實車做**：黃色平頭（cab-over）底盤共用，一般垃圾車是**封閉壓縮箱＋階梯狀後斗＋深凹投棄槽＋紅色識別板**；資源回收車是**通透綠色鐵網籠架＋三個分類箱**，完全沒有壓縮口。四歲小孩靠「封閉大箱 vs 看得到分類箱」就分得出來，紅綠只是第二層提示
- **收集車各四種表情**：平常微笑 → 收到垃圾瞇眼笑 → 丟錯嘟嘴嫌棄 → 收滿垃圾用力壓縮（腮幫子鼓起）
- **車子開得很慢**：從畫面一側走到另一側約 7 秒，走 4.6～6.4 秒停 1.3～1.9 秒，兩台不會同時停——小孩要一直左右跟過去，才有「追垃圾車」的感覺
- **小主人八張影格**：站立、跑步兩格（真的換腳）、舉手預備、揮手丟出、大笑（丟到路人車時）、垃圾桶機器人兩格
- **街景車有「平常」與「被砸到」兩張表情**（各五種車，共十張）——命中前後的對比才是小玩家最愛看的部分
- **《給愛麗絲》音符**：垃圾車靠近時音樂變大聲，車上會淡淡飄出音符
- 旁白 21 句 Gemini TTS（`snd/*.mp3`），沒有 mp3 時自動退回瀏覽器合成語音
- 原版 `index.html` 完全未動，選單兩版並列

### 🚗 砸到路上車車的反應（兒子最愛的部分）

每一次命中都走同一條時間軸，刺激集中在被砸的那一台，**不震整個畫面**：

| 時間 | 發生什麼 |
|---|---|
| 0 ～ 0.09 秒 | 只有被砸的那台車往下頓一下，其他東西照常 |
| 0.09 ～ 1.35 秒 | 換成「被砸到」的表情圖，做該車專屬動作；命中點冒一朵小煙 |
| 1.35 ～ 3.0 秒 | 以平滑曲線加速到 1.6 倍逃走 |
| 全程 0.9 秒 | 小主人捧腹大笑（CH008） |

| 車種 | 反應 |
|---|---|
| 🚗 轎車 | 嚇得往上跳一下，再左右擺三次逐漸縮小，兩聲短喇叭 |
| 🚕 計程車 | 像急煞一樣車頭下沉再回彈，車頂燈箱亮暗兩輪（實色淡色塊，不加光暈） |
| 🚌 公車 | 長車身後仰、垂直壓扁到 92% ／水平拉寬到 103% 再慢慢回彈，車尾冒一朵煙，一聲低沉喇叭 |
| 🛵 機車 | 連人帶車東倒西歪四次（但不會真的倒），三聲小小的「嗶」 |
| 🚓 警車 | 一本正經地被嚇到：垂直小跳兩次＋僵硬左右擺，車頂紅／藍交換兩輪 |

閃爍一律**每秒最多兩次、總共兩輪**，不會一直閃。

### 這一版刻意「不華麗」

爸爸回饋過「畫面過於華麗，對四歲小朋友視覺刺激太強」，所以這款從素材到程式都主動節制：

| 項目 | 做法 |
|---|---|
| 配色 | 全部粉彩低飽和低對比（霧面漆玩具感），不用霓虹、不用高飽和原色 |
| 特效素材 | 星星／煙／音符只用兩種柔和顏色、稀疏、大量留白，像貼紙不像爆炸 |
| 粒子數量 | 命中最多 6 顆星星（原版最多 20 顆 emoji），煙霧一次 1～3 朵 |
| 畫面震動 | 上限 6（原版 10）且衰減更快；街景車被砸**完全不震畫面**（原版會震），刺激集中在那一台車身上 |
| 閃爍頻率 | 警示燈每秒 2 次、只閃兩輪（原版 16Hz 一直閃）；一次只有一台車在動 |
| 大絕特效 | 原版是全螢幕 disco 彩光 hue-rotate → 改成小主人身上一圈很淡的暖色光暈 |
| 街景密度 | 同畫面 4 台街景車（原版 6 台），車速放慢 |
| 垃圾雨 | 狂歡時的垃圾雨密度砍到原版的 1/5 |

## 玩法（和原版相同）

- **左右移動身體** → 小主人在人行道上左右跑，追著垃圾車
- **用力揮手** → 把手上的垃圾丟出去，自動鎖定最近的目標
  - ❤️ 一般垃圾（垃圾袋／便當盒／香蕉皮）→ **紅框壓縮式垃圾車**（封閉大箱、後面有投棄槽）
  - 💚 資源回收（寶特瓶／紙箱／鋁罐）→ **綠籠資源回收車**（看得到裡面的分類箱）
  - 🎁 金色禮物盒 → 丟哪一台都算對，加 5 倍分
- **丟錯車**：垃圾彈開、車子嘟嘴嫌棄、連擊歸零——**不是懲罰，是好笑的**
- **丟到路上的車車**：純搞笑，不扣分也不破連擊，小主人會大笑
- **收集車收滿 6 件**會壓縮一次（車斗擠一下、噴煙、車速加快一點點）
- **雙手高舉**（能量條滿時）→ 變身垃圾桶機器人 7 秒，自動連發、一定命中
- 沒有 Game Over、沒有倒數，丟歪只會掉地上冒一朵煙
- **🛑 護眼提醒**：跑太靠近電視（約 1 公尺內）→ 警報音 + 遊戲強制暫停 5 秒（畫面倒數），退後才能繼續玩

## 投影設置步驟（手機投到電視）

1. 手機和 Chromecast 連同一個 Wi-Fi（**建議用 5GHz**，投影才順）
2. 打開手機的 **Google Home App** → 選擇 Chromecast → **投放我的螢幕**
3. 手機**橫放**在電視上方，**前鏡頭朝向沙發/玩的地方**
4. 在手機 Chrome 打開遊戲網址，按「🏃 用身體玩」
5. 允許鏡頭權限 → 小朋友站到電視前面約 1.5～3 公尺 → 開始！

### 小技巧

- 房間燈光要夠亮，鏡頭才看得清楚
- 左下角有鏡頭小視窗：綠點 = 偵測到的位置，揮手變黃點、雙手高舉變粉點；確認沒問題可按 ✕ 關掉
- 揮手要**用力往上揮**（門檻設得高是為了防止小孩亂動誤觸）
- 影像全部在手機上即時運算，**不會上傳到任何伺服器**

## 在電腦上測試

用 Chrome 開 `index-新美術.html`，按「👆 用手指玩」：拖曳移動、點一下丟垃圾、點畫面上方 1/4 放大絕。
有 webcam 的話「用身體玩」在電腦上也能跑（需要 localhost 或 HTTPS）。

## 素材與重製流程

- `G5-現況與重製方向.md`　現況盤點與這次重製的方向（給 GPT 讀的第一份文件）
- `AGENTS.md`　畫風與每張圖的鐵則（Codex CLI 自動讀）
- `plan.md` / `scene.md`　GPT 產的企劃書與場景設計
- `assets.json`　39 張素材的 prompt 與後處理參數（`assets.gpt.json` 是 GPT 原稿）
- `voice-lines.json`　21 句旁白台詞與演出指示
- `pic/_ref/`　設定圖 REF001（台灣平頭清潔車底盤）、REF002（小主人）、REF101（街景）、REF111～115（街景車造型基準）
- `pic/_raw/`（不進 repo）→ `pic/opt/`（遊戲實際載入的 webp/jpg）

重跑素材：

```bash
素材工作流/tools/gen-images.sh "遊戲5-垃圾車來囉"          # 生圖（已存在的會跳過）
素材工作流/tools/build.ps1 -Game "遊戲5-垃圾車來囉"        # 去背＋裁切＋縮圖
# ⚠️ 小主人的腿縫、回收車的鐵網籠縫、機車輪下都是「被主體包住的洋紅」，邊緣 flood-fill 到不了。
# 而且模型每次生的洋紅濃度不一樣（實測從 m=71 到 m=244 都有），所以用 auto 讓它按每張圖自己的底色算門檻：
for id in VH005 VH006 VH007 VH008 VH104 VH109 CH001 CH002 CH003 CH004 CH005 CH006 CH007 CH008; do
  python 素材工作流/tools/chroma-global.py "遊戲5-垃圾車來囉" $id auto 0.65
done
node 素材工作流/tools/tts-gemini.js voice-lines.json snd   # 旁白（已存在的會跳過）
```

## 技術備註

- 單一 HTML 檔，無需安裝；2D Canvas `drawImage`，不再依賴 Three.js CDN
- 人體偵測：MediaPipe Pose Landmarker（CDN 載入，需要網路）
- ⚠️ 鏡頭功能需要 **HTTPS 網址或 localhost**（瀏覽器安全限制）
- 自動驗證勾子：`window.__sim(秒數, {kidX, truckX, held, throw, energy, armsUp, …})` 推進遊戲並回傳狀態；`window.__art()` 列出載入失敗的素材
