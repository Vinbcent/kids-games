# 遊戲5-垃圾車來囉 場景設計

## 一、場景概念

場景是一條安靜、親切的台灣住宅街道。《給愛麗絲》響起時，紅色一般垃圾車與綠色資源回收車沿著街道走走停停，小主人站在前景人行道上左右移動，把手中的垃圾丟向正確車斗。

整體採立體卡通 CG 玩具質感，造型圓潤、無黑色描邊、表面像霧面塑膠。畫面使用粉彩、低飽和、低對比配色，避免華麗裝飾與刺激性特效。場景氣氛熱鬧但不擁擠，任何時刻都要保留足夠空白，讓四歲玩家能迅速看懂小主人、手上垃圾與兩台主要收集車。

場景只更換美術呈現，不改變既有玩法、操作、判定、車輛節奏與垃圾狂歡流程。

## 二、鏡頭與畫面規格

### 基本鏡頭

- 固定側視鏡頭，以橫向 16:9 畫面為主要構圖。
- 採正投影感的 2D Canvas 畫面，不使用透視旋轉或斜角鏡頭。
- 所有車輛維持完整正側面。
- 收集車車頭朝右，由左往右行駛。
- 街景車車頭朝左，由右往左行駛。
- 小主人與垃圾桶機器人採側背四分之三視角，從角色背後看向街道。
- 鏡頭全程固定，不跟隨單一車輛，不使用快速推拉、旋轉、震動或閃白。
- 縱深以固定尺寸、上下位置、遮擋關係及色彩濃淡表現，不使用強烈景深模糊。

### 邏輯座標

以畫面左上角為 `(0%, 0%)`、右下角為 `(100%, 100%)`。

主要遊戲內容集中在中央約 92% 寬度內。不同螢幕比例下，天空、街屋、道路與人行道可以向左右延伸，但兩台收集車、小主人、投擲路徑與主要 HUD 不可被裁切。

### 深度比例

| 深度 | 尺寸基準 | 色彩與清晰度 |
|---|---:|---|
| 街景車流 | 約 0.62 | 比收集車稍淡、細節較少 |
| 收集車 | 1.00 | 主要辨識基準，輪廓最清楚 |
| 小主人／垃圾桶機器人 | 約 1.15 | 前景最大角色，色彩略清楚但不鮮豔 |

## 三、四層場景構圖

### 第一層：天空、遠山與台灣街屋

| 項目 | 設計 |
|---|---|
| 使用素材 | BG001 |
| 畫面範圍 | 滿版鋪底，主要可見內容約在 `Y=0%～48%` |
| 天空 | 淡藍色，約佔畫面上方三成；保持大片乾淨留白 |
| 雲朵 | 奶油白、圓潤簡化，數量少，不使用高亮邊緣 |
| 遠山 | 低矮淡黃綠丘陵，約落在 `Y=20%～35%` |
| 街屋 | 約落在 `Y=24%～49%`，形成一整排台灣透天厝 |
| 動態 | 靜止或以極慢速度水平平移，不做視差快速滑動 |

街屋以二至三層樓透天厝為主，使用米色、淡奶茶、淺磚紅與奶油白。屋頂、窗戶、鐵窗和遮雨棚均簡化成大色塊，不安排過密的電線、招牌、盆栽或廣告。

一樓店面招牌保留乾淨空白色塊，畫面素材內不出現任何文字、數字、字母、商標或品牌圖案。建築不得使用霓虹燈、發光招牌、鏡面玻璃或強烈金屬反射。

### 第二層：遠方街景車道

| 項目 | 設計 |
|---|---|
| 畫面範圍 | 約 `Y=43%～64%` |
| 車輛基準線 | 約 `Y=61%` |
| 行駛方向 | 由右往左 |
| 使用素材 | VH101～VH105、BG002 |
| 尺寸 | 約為收集車的 0.62 倍 |
| 功能 | 次要搞笑目標，不能搶走兩台收集車的視覺焦點 |

小轎車、計程車、公車、機車與警車依序穿插出現。同一時間以一至兩台街景車為原則，車距保持寬鬆；公車雖然較長，也不能遮住兩台主要收集車的車斗投入口。

遠車道車輛色彩比收集車稍淡，輪廓仍需清楚。車輛被垃圾命中時，只播放短暫、柔和的滑稽反應：

| 車輛 | 反應 |
|---|---|
| VH101 小轎車 | 車身輕搖，雨刷左右擺動一次 |
| VH102 計程車 | 車燈以兩塊不發光的淡黃色平面交替顯示 |
| VH103 公車 | 車身微微後仰，車尾冒出一小團深灰米色煙 |
| VH104 機車與騎士 | 以小角度左右搖晃，再恢復平衡 |
| VH105 警車 | 車頂紅、淡藍警示色塊緩慢交替，不加光暈 |

反應結束後車輛稍微加速離開。不得使用高速殘影、速度線、畫面震動或強烈閃爍。

### 第三層：主要收集車道

| 項目 | 設計 |
|---|---|
| 畫面範圍 | 約 `Y=62%～83%` |
| 車輪基準線 | 約 `Y=80%` |
| 行駛方向 | 由左往右 |
| 使用素材 | VH001～VH008、BG002 |
| 尺寸 | 主要車輛基準 1.00 |
| 功能 | 一般垃圾與資源回收物的主要投擲目標 |

紅色一般垃圾車和綠色資源回收車維持不同水平位置，不互相重疊。兩車使用相同系列的黃色車頭與圓潤比例，靠霧面紅色車斗、霧面綠色車斗及程式疊加的中文分類提示區分。

車斗後方投入口必須保持可見。若兩車在畫面上靠近，後進入的車要放慢或停在較遠位置，不可讓其中一台遮住另一台的投入口。

兩台車依原玩法行駛三至六秒、停車一點六至三點二秒。停車按喇叭時，車身只做一次幅度很小的上下彈動，不出現音波、爆炸圖形或高亮閃光。

收集車狀態如下：

| 車輛 | 平常 | 正確投入 | 錯誤投入 | 壓縮 |
|---|---|---|---|---|
| 一般垃圾車 | VH001 | VH002 | VH003 | VH004 |
| 資源回收車 | VH005 | VH006 | VH007 | VH008 |

正確投入時，車輛切換成月牙眼開心表情，車斗蓋微微掀起，投入口附近短暫出現一組 FX001。錯誤投入時切換成嘟嘴嫌棄表情，垃圾以小拋物線彈開；表情必須好笑，不能兇狠或令人害怕。

每台車收到六件正確垃圾後進行壓縮。車斗短暫向內縮約 8%～12%，車輛閉眼鼓起腮幫子，再以柔和回彈恢復原狀。壓縮完成後只稍微提高行駛速度，不改變車輛尺寸與配色。

### 第四層：前景人行道與小主人

| 項目 | 設計 |
|---|---|
| 畫面範圍 | 約 `Y=82%～100%` |
| 腳底基準線 | 約 `Y=97%` |
| 使用素材 | BG003、CH001～CH008 |
| 角色尺寸 | 約為深度基準 1.15 |
| 可移動範圍 | 畫面中央約 80% 寬度 |

BG003 沿畫面底部水平無縫鋪設。紅磚圖案使用大尺寸、低對比的規律拼接，避免細碎紋理。米白色路緣石位於人行道上緣，清楚分隔小主人與收集車道。

小主人始終面向街道，左右移動時不需要改成正面或完全側面。跑步使用 CH002、CH003 交替，兩影格節奏平穩，不做快速抖動。停止移動時回到 CH001。

| 行為 | 素材與動作 |
|---|---|
| 待機 | CH001，身體以很小幅度呼吸起伏 |
| 左右跑動 | CH002、CH003 交替，腳步頻率保持柔和 |
| 投擲預備 | CH004，雙手高舉、身體微後仰 |
| 完成投擲 | CH005，手臂向街道揮下、身體前傾 |
| 命中街景車 | CH008，後仰並扶肚大笑一次 |
| 垃圾狂歡待機 | CH006 |
| 垃圾狂歡歡呼 | CH007 |

角色可在街道兩側移動，但頭部、帽子、手臂與鞋子任何時候都不得被畫布裁切。

## 四、道路與空間銜接

BG002 從約 `Y=43%` 延伸至 `Y=83%`，形成一整片乾淨的灰色柏油路。淡黃色雙黃線位於兩條車道之間，約落在 `Y=61%～64%`，同時作為遠車道與收集車道的視覺分界。

道路不放置人孔蓋、路邊垃圾、文字標線、斑馬線、路障或其他會被誤認為投擲目標的物件。路面不使用水漬反光、強烈陰影或複雜裂紋。

畫面遮擋順序由後至前為：

1. BG001 天空、遠山與街屋。
2. BG002 柏油路。
3. 遠車道街景車。
4. 雙黃線與車道分界。
5. 收集車道車輛。
6. BG003 路緣石與人行道。
7. 小主人或垃圾桶機器人。
8. 飛行中的垃圾、必要回饋與 HUD。

所有素材依輪胎或腳底基準線定位，不額外增加地面投影陰影。

## 五、主要動線與投擲路徑

### 車流動線

- 遠車道車流從畫面右側外進入，向左行駛並從左側離開。
- 兩台收集車從畫面左側外進入，向右走走停停並從右側離開。
- 兩個方向相反的車流形成清楚但平穩的橫向動態。
- 同一時間的車輛數量保持克制，不讓畫面形成塞車感。
- 車輛進出畫面時，完整車身應先在畫布外，再平順移入；不可突然出現或消失。

### 垃圾拋物線

垃圾從小主人手部附近出發，先向上、再向目標落下：

| 階段 | 大致位置與尺寸 |
|---|---|
| 起點 | `Y=78%～88%`，尺寸 1.00 |
| 拋物線頂點 | `Y=48%～62%`，尺寸約 0.70 |
| 收集車目標 | 投入口附近，尺寸約 0.55～0.65 |
| 街景車目標 | 遠車道車身附近，尺寸約 0.40～0.50 |

垃圾飛行時只改變位置、角度與尺寸，不加速度線、拖尾、粒子、發光或動態模糊。飛行物永遠顯示在可辨識的最上層，命中投入口後立即收起，不讓物件穿過車斗。

沒有可鎖定目標時，垃圾落在收集車道空位，輕彈一次並冒出一小朵煙後消失。煙由二至三個相疊的圓潤霧面色塊構成，只使用奶油灰與淡灰褐兩色。

## 七、光線與景深

- 全場使用柔和、均勻的上方偏左頂光。
- 天空與街屋亮度最低，街景車稍淡，收集車與小主人輪廓最清楚。
- 陰影只存在於角色模型本身的柔和明暗轉折，不在路面增加投影。
- 不使用逆光、輪廓光、鏡頭光暈、光束、放射線或閃爍曝光。
- 遠近差異主要依尺寸與飽和度處理，不用重度模糊。
- 垃圾狂歡期間仍維持相同整體照明，不切換成舞台燈、彩色燈或夜景。

## 八、場景狀態與回饋

| 狀態 | 場景表現 |
|---|---|
| 開場 | BG001、BG002、BG003 已完整顯示；兩台收集車由左側平順進場，小主人在前景示範左右移動與投擲 |
| 一般遊玩 | 街景車向左、收集車向右，小主人在人行道左右跑動 |
| 正確投入 | 車輛切換開心狀態，投入口旁出現一次稀疏 FX001，隨即恢復 |
| 錯誤投入 | 垃圾柔和彈開，收集車切換嘟嘴嫌棄狀態，不改變背景與鏡頭 |
| 命中街景車 | 該車播放專屬搞笑反應後加速離開，小主人短暫切換 CH008 |
| 落到路面 | 垃圾輕彈一次，出現一小朵雙色煙團後消失 |
| 車斗壓縮 | 車輛切換壓縮狀態，車斗縮放一次，搭配一小團煙與少量 FX001 |
| 能量全滿 | 能量條緩慢彈動，小主人維持正常尺度，不使用閃白或滿版特效 |
| 垃圾狂歡 | 小主人切換為垃圾桶機器人，自動投擲；天空區稀疏落下垃圾物件 |
| 狂歡結束 | 垃圾雨停止，空中物件清除，角色恢復小主人，回到一般車流 |
| 護眼暫停 | 所有車流、角色、投擲物與動畫同步凍結，沿用全系列護眼遮罩，不新增場景素材 |

### 垃圾狂歡的視覺限制

垃圾狂歡維持七秒，但畫面不得變成密集爆發：

- 同時可見的垃圾雨物件保持少量並拉開間距。
- 垃圾雨只使用 IT001～IT006，不增加新的彩色碎屑。
- 自動投擲仍沿一般拋物線飛行。
- FX001 每次只短暫出現一組，不重疊成滿版星星。
- 不使用彩虹、雷射、煙火、光柱、鏡頭震動、畫面旋轉或高頻閃爍。
- 背景、道路與街屋色彩不隨狂歡變色。

## 九、HUD 與安全區

HUD 固定在畫面邊緣，使用奶油白半透明霧面面板、藍灰文字與圓角造型。所有畫面文字使用中文；語音台詞使用英文。HUD 不遮擋收集車投入口、垃圾拋物線或小主人頭部。

| 區域 | 內容 | 建議位置 |
|---|---|---|
| 左上 | 當前垃圾縮圖與「一般垃圾」或「資源回收」中文提示 | `X=2%～19%`、`Y=2%～13%` |
| 上方中央 | 歡樂能量條 | `X=30%～70%`、`Y=2%～8%` |
| 能量條下方 | 紅車與綠車各自的六件收集進度 | `X=34%～66%`、`Y=8%～13%` |
| 右上 | 分數與連擊 | `X=80%～98%`、`Y=2%～13%` |
| 下方右側 | 觸控模式的大型「丟」圖示按鈕；能量滿時顯示狂歡按鈕 | 避開小主人目前位置與路緣石 |
| 下方左側 | 體感模式的攝影預覽保留區 | 不遮擋主要車道與收集車投入口 |

分類提示以垃圾實物縮圖和紅、綠霧面色塊共同表達，不只依靠文字。能量全滿時只做低頻率、低幅度彈跳，不使用快速閃爍或發光外框。

開場示範所需的方向箭頭與手臂動作提示使用簡單奶油白、淡黃色平面圖形，畫面一次只顯示一個重點。示範提示不得覆蓋兩台收集車。

## 十一、素材一致性與禁用項目

- VH001～VH004 必須是同一台紅色垃圾車，只改表情、車斗蓋與壓縮姿勢。
- VH005～VH008 必須是同一台綠色回收車，只改表情、車斗蓋與壓縮姿勢。
- CH001～CH005、CH008 的身高、頭身比、帽子、髮型、衣服與鞋子完全一致。
- CH006、CH007 的桶身、桶蓋、手臂結構與配色完全一致。
- 所有車輛保持指定朝向，不以斜角、正面或三分之四車身替代。
- 所有角色、車輛與物件均採原創造型，不模仿現有卡通、動畫、遊戲或品牌。
- 車身、招牌、罐子、紙箱與建築素材內不得出現文字、數字、字母、車牌、商標、簽名或浮水印。
- 前景單體素材以純洋紅底製作，去背後貼入場景；BG001、BG002、BG003 為滿版例外。
- 不增加電線桿、行人、動物、攤販、路樹或其他未列入素材表的搶眼主體。
- 不使用霓虹色、高飽和原色、金屬高反光、爆閃漸層、光暈、速度線、動態模糊或密集粒子。
- 任一時刻都以「小主人手上的垃圾、紅色垃圾車、綠色回收車」為第一閱讀順序；街屋、街景車與特效只提供環境和笑點，不可搶走焦點。
