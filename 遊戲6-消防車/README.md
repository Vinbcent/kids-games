# 🚒 消防車救援隊（遊戲 6）

## 🎨 新美術版（2026-08-24，玩法重新設計）

`index-新美術.html` 是**玩法整個重做**的版本，原版 `index.html`（Three.js 橫向捲動、雙手握在一起噴水）保留不動。

原版不好玩的原因：主要動作「雙手握在一起」骨架判讀抓不穩、噴水忽開忽關；世界一直往前捲、火 3 秒沒滅就燒焦跑掉，對 4 歲小孩是時間壓力。

### 新玩法（站對位置就全自動）

- **左右移動身體**（主操作）：把消防車開到「跳跳的窗戶」正下方 → 水柱自動往上噴、火苗變蒸氣 → 雲梯自動伸出去 → 小動物滑進籃子、坐進消防車。站錯只會噴出好笑的水花（消防栓打噴嚏、花叢跳一下），火不會變大、動物不會跑掉。
- **蹲下**（每救 2～3 隻穿插一次屋頂救援）：蹲下把充氣墊壓扁蓄力、站起來「蹦」彈出接住屋頂上的小動物。
- **雙手高舉**（坐滿五隻時）：全員水花派對——大水砲扇形水幕、帽子沖上天、煙火，然後小動物進休息站揮手，新一輪開始。
- 沒有失敗、沒有倒數；三個訊號分階段只啟用一種，互不搶判定。
- 六種小動物（貓、狗、兔、鴨、刺蝟、松鼠）輪流出場，房子每輪重新排列。

### 素材與旁白

- 30 張 AI 生成素材（`pic/opt/*.webp`）：消防車 2 態＋雲梯＋水砲、五棟糖果色房子、休息站、充氣墊、六隻動物、火苗 2 態、水柱／水花／蒸氣／水滴／扇形水幕／帽子／消防栓、四層背景橫幅。
- 17 句英文旁白（`snd/*.mp3`，Gemini TTS；缺檔退回瀏覽器語音），畫面同步中文字幕。
- 企劃／場景／素材清單：`G6-現況與重製方向.md`、`plan.md`、`scene.md`、`assets.json`、`voice-lines.json`。

## 手指模式

找窗：在街道上左右拖曳；屋頂救援：按住畫面＝蹲下、放開＝站起；派對：按住畫面半秒。

## 📺 投影到電視

和其他遊戲相同：手機用 Google Home「投放我的螢幕」到 Chromecast，手機橫放電視上方、鏡頭朝玩的人，選「🏃 用身體玩」。

## 技術備註

單一 HTML 檔（2D Canvas），人體偵測 MediaPipe Pose Landmarker（影像只在裝置本機運算，不上傳）；鏡頭功能需要 HTTPS 或 localhost；橫式設計。
