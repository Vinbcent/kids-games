# 🌻 遊戲9 花市小老闆

台灣社區花市的小花攤：**走過去選花盆 → 雙手高舉把花放進去 → 手一直舉著幫它澆水看它長高開花 → 擺滿五格花架**。
配錯不會有任何挫折（盆搖搖頭 → 小花自己咕嚕咕嚕滑到對的盆 → 照樣開花），蹲一下可以讓整盆花倒轉再轉正，想玩幾次都行。

| | |
|---|---|
| 玩家 | 5 歲，不識字 |
| 體感訊號 | 身體左右移動（三個盆拉開，要走過去）／雙手高舉（1 秒＝放花，之後持續舉著＝澆水）／蹲下（有蜜蜂＝嚇跑牠，沒有＝整盆倒轉） |
| 觸控備援 | 點畫面或直接點盆＝選盆；按住「🌱 放花」＝放花與澆水；點「🔄 轉一圈」＝倒轉／趕蜜蜂 |
| 澆水 | 舉著手花就一直長，放下就停；不澆也不會失敗，超過 5 秒沒人澆就自己長完 |
| 五種花 | 向日葵／蝴蝶蘭／九重葛／聖誕紅／含笑（靠**剪影**分辨，不靠顏色） |
| 語音 | 英文短句（磨耳朵），畫面字幕繁體中文 |
| 護眼 | 肩寬 > 0.28 持續 0.4 秒 → 強制暫停 5 秒；解除採「清場」，花／盆／花架全部保留 |
| 無 Game Over | 沒有失敗、沒有計時、沒有重試；五盆擺滿後自己決定要不要再擺一架 |

## 開發勾子（瀏覽器 console）

```js
__art()                      // 列出載不到的素材
__dbg()                      // 現在的階段、選了哪個盆、花架進度
__step(5, {sel:1, arms:true})// 手動快轉 5 秒（不靠 rAF，背景分頁也能跑）
__sim(5, {wrong:0.4})        // 自動玩五盆，四成故意放錯；{water:false} 測「完全不澆水」
__bee()                      // 叫小蜜蜂出來搗蛋（蹲下可以趕走）
```
